## Components

### Core Application Layer
- **Location:** `app/`, `components/dashboard/`, `components/ui/`
- **Purpose:** Delivers the interactive frontend. Adheres to an adaptive skeleton-loading paradigm (`PageSkeleton`) to prevent CLS, wrapped with highly resilient `PanelErrorBoundary` barriers for isolated runtime failures.

### tRPC API Backbone
- **Location:** `server/routers/`, `server/trpc.ts`
- **Purpose:** Strongly typed API layer exposing 15+ sub-routers (Trello, LOD, KPI, Search). Uses multi-tiered middleware (Admin vs standard User logic).

### Domain-Driven Utility Libraries
- **Location:** `lib/core/`, `lib/google/`, `lib/wiki/`, `lib/trello/`, `lib/events/`
- **Purpose:** Business logic separated strictly by domain to prevent cyclic dependencies. Handles Gmail inbox fetching, OAuth token refreshing, and global localized event emitters.

### LOD Semantic Hub (Image-to-RAG)
- **Location:** `services/lod-engine/`, `server/routers/lod.ts`, `scripts/migrate-lod-data.cjs`
- **Purpose:** A Python-based inference engine that embeds BIM model images. Data is persisted in PostgreSQL using `pgvector` (HNSW indexing) allowing sub-second visual similarity searches. Images are efficiently routed through a Google Drive proxy (`/api/lod-img/`) to sidestep Vercel/Railway bandwidth egress costs.

### Wiki Subsystem & Real-Time Sync
- **Location:** `components/clash/WikiEditor.tsx`, `scripts/yjs-server.cjs`
- **Purpose:** Provides a Notion-like multi-player rich-text editor using Tiptap and Yjs.

## Data Flow

1. **Authentication:** Users authenticate via NextAuth (Google/Azure/Credentials). `middleware.ts` intercepts protected routes, bouncing unauthenticated requests while permitting hardcoded `PUBLIC_PATHS` (like webhooks and `/api/health`).
2. **Client queries:** React components utilize `@tanstack/react-query` wrappers generated by tRPC to query the backend. Lookups often hit `LodSearchCache` or active Prisma tables.
3. **Real-time streams:** Chat panels and status indicators subscribe to Server-Sent Events (`/api/chat/stream`) and WebSockets (`ws://localhost:4444` for Wiki).
4. **Third-Party mutations:** Creating a clash issue dispatches robust API requests to Trello, managed implicitly by the `trelloEvents` bus.

## Technical Debt (Consolidated Backlog)

Following the Spring cleanup and native migration, these are the remaining identified debt items synthesized from the `technicaldebt*.md` files:

- [ ] **Infrastructure - Redis:** Search results are currently cached in a Postgres table (`LodSearchCache`). Introducing Redis would strip 50ms of latency penalty.
- [ ] **VRAM & GPU Affinity:** The Python `lod-engine` inference (`SiglipModel`) does not currently enforce FP16 mixed precision or TensorRT execution, leaving silicon utilization unoptimized.
- [ ] **Binary Streaming:** The LOD Graph returns 24k nodes over HTTP JSON. Integrating Protobuf or FlatBuffers would drastically reduce deserialization CPU overhead.
- [ ] **Push Notifications:** The Mail panel polling should be upgraded to Google Pub/Sub webhooks for instant arrival alerts.
- [ ] **Wiki State Safety:** Yjs persistence mechanisms need to be made explicit and repairable to prevent data corruption during container lifecycle restarts.

## Conventions

- **Structural Safety:** Import paths must rely on the structured `lib/` domains.
- **Styles:** Vanilla Tailwind v4 with the `cn()` utility `clsx/tailwind-merge` pipeline.
- **Port Binds:** Next.js servers and container workflows exclusively respect `process.env.PORT` to satisfy Railway's dynamic inbound traffic proxies.
- **Type Safety:** `any` casting is strictly prohibited in the `server/` directory. Outputs must be parsed through strict Zod schemas.
