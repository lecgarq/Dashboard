## DevOps & Environment Logic

### Environment Patching

The system uses `scripts/patch-env.js` to automatically detect the host's local IP address and propagate it to the `.env` settings. This ensures that the Yjs server and internal service interlinks function correctly across tunneling services and local Wi-Fi networks.

### Multi-Service Orchestration

The primary entry point for development is `scripts/run_dev_stack.py`. This Python orchestrator:

1. Validates PostgreSQL status.
2. Clears the `.next` cache to avoid stale static generation issues.
3. Automatically frees required ports by killing conflicting PIDs.
4. Concurrently launches the Dashboard, Yjs Server, and LOD Checker with prefixed logging.

## Configuration

The application uses environment variables defined in `.env`. Key variables include:

- `DATABASE_URL`: Connection string for PostgreSQL.
- `NEXTAUTH_SECRET`: Secret key for session encryption.
- `APS_CLIENT_ID` / `APS_CLIENT_SECRET`: Autodesk credentials.
- `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`: Google OAuth credentials.
- `UPLOADTHING_SECRET` / `UPLOADTHING_APP_ID`: UploadThing credentials.
- `TRELLO_API_KEY` / `TRELLO_TOKEN`: Trello integration keys.
