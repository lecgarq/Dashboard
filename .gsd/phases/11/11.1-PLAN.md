# Plan 11.1: Abstract Vector Memory into `ioredis` 

## Objective
The `pgvector` models natively throttle schema querying locking rows during massive analytical matrices searches via operators like `<->`. This plan establishes an `ioredis` framework explicitly breaking the `LodSearchCache` out of the standard `Prisma` environment routing it cleanly toward Upstash / managed Redis architectures.
