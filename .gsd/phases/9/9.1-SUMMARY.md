# Summary: Family Kanban Virtualization

## What was built

Installed `@tanstack/react-virtual` and refactored `components/families/KanbanBoard.tsx` so each family phase column renders through `useVirtualizer` instead of a full `families.map()` pass. Each `DroppableColumn` now uses a scroll container, `estimateSize: 88`, `overscan: 5`, and absolute-positioned rows inside a relative inner viewport.

The drag shell remains intact. `DndContext`, `SortableContext`, and `DragOverlay` still wrap the board, while the virtual row index is passed through the card move handler so reordered items can still resolve a position within the rendered window.

## Files modified

- `package.json`
- `package-lock.json`
- `components/families/KanbanBoard.tsx`

## Outcome

The family Kanban implementation now caps rendered DOM nodes per column to the active virtual window rather than the full backlog size. This reduces render pressure for large boards and keeps the drag UI mounted separately from the list viewport.
