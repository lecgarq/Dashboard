  <files>prisma/schema.prisma</files>
  <action>
Append the following model to prisma/schema.prisma after the existing LodCategory model (end of file). Do NOT modify any existing model.

```prisma
// ============ MODULE: ACC MEMBER CACHE ============

model AccMemberCache {
  id        String   @id @default(cuid())
  email     String   @unique
  data      Json
  syncedAt  DateTime
  createdAt DateTime @default(now())

  @@index([email])
  @@index([syncedAt])
}
```

The `data` field uses Prisma's `Json` type (maps to PostgreSQL `jsonb`). It will store the full AccProfile object serialized by the tRPC procedure — either `{ found: false, syncedAt: string }` or `{ found: true, autodeskId, name, status, projects: [...], products: [...], syncedAt: string }`.

The `syncedAt` field is NOT auto-managed by Prisma (no `@default(now())`). The procedure sets it explicitly on every upsert so the cache TTL logic (`Date.now() - cached.syncedAt.getTime() < CACHE_TTL_MS`) works correctly.
