    Run, in this exact order (PowerShell):

    ```
    Stop-ScheduledTask -TaskName "LECG Dashboard Local"

    $proc = Get-NetTCPConnection -LocalPort 3000 -ErrorAction SilentlyContinue |
      Select-Object -ExpandProperty OwningProcess -Unique
    if ($proc) { Stop-Process -Id $proc -Force }

    npx tsc --noEmit          # MUST exit 0 before the build. If it fails, ABORT:
                              # restart the task and report. Do not build a broken tree.
    npm run build             # `next build --webpack` (package.json)

    Start-ScheduledTask -TaskName "LECG Dashboard Local"
    ```

    CRITICAL (project memory, standing rule): NEVER run `npm run build` while `:3000` is
    live — it 500s the running app. The Stop-ScheduledTask + port-kill steps above are the
    guard, and they must complete before `npm run build` starts.

    Brief live downtime is accepted and expected (locked in CONTEXT.md). There is no
    isolated `:3100` preflight this time — the review target IS `:3000`.

    After restart, probe:
    - `curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/health` → expect `200`
