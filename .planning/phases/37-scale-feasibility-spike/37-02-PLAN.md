# Plan 37-02 — Binary payload prototype (SCALE-01 track b)

## Objective

Measure the thing that replaces JSON at 4.86M: a raw typed-array columnar payload
served by a route handler, timed end-to-end (wire → decode → GPU upload). Numbers
ground the Phase-38 SCALE-02 time-to-graph budget.

## Context

- @.planning/phases/37-scale-feasibility-spike/37-CONTEXT.md (decision 4: raw buffers, zero deps; Arrow rejected barring evidence)
- @app/(dashboard)/users/scale-spike/spikeSynthetic.ts (37-01 generator — the server route reuses it for deterministic content)
- @lib/server/graphSnapshotCompression.ts (the 22k-scale JSON path being replaced — reference only, do not modify)

## Tasks

1. **`columnar.ts`** — pure encode/decode: layout = 4-byte header-length prefix + UTF-8 JSON header `{count, columns:[{name,dtype,byteOffset,byteLength}]}` + 4-byte-aligned column buffers. `encodeColumnarPayload(columns)` → ArrayBuffer; `decodeColumnarPayload(buf)` → named typed-array views (zero-copy subarrays where alignment allows). No deps.
2. **`route.ts`** (`app/api/scale-spike/payload/route.ts`) — GET, flag off → 404. Params `?n=` (default 4,862,301) `&seed=`. Generates positions (downprojected to stride-2 Float32) + attribute columns via `spikeSynthetic`, encodes, returns `application/octet-stream` with `Content-Length`. `export const dynamic = "force-dynamic"`. Note in-route comment: synthetic content, Phase-38 replaces the generator with the real table read; format is the deliverable.
3. **Client payload scenario** — extend `ScaleSpikeClient.tsx` bridge with `runPayload()`: `performance.now()` marks around fetch→arrayBuffer (wire), decode (parse), `handle.setPointSet(positions, colors)` (upload; colors derived client-side from the verb column to include realistic derived-buffer cost). Record bytes (Content-Length + buffer byteLength), each phase ms, and totals on `window.__SCALE_SPIKE__.results.payload`.
4. **`columnar.test.ts`** — roundtrip: encode 3 columns (Float32/Uint16/Uint8, odd lengths for alignment padding) → decode → byte-identical values; header rejects truncated buffers with a thrown error (no silent partial decode).
