# Plan 37-03 — Embedding runtime estimate (SCALE-01 track c)

## Objective

Measured sample-fit evidence for the Phase-38 EMB-07 decision: full-fit PaCMAP vs
sample-fit + faiss kNN projection at activity grain. Estimate only; no pipeline,
no table, no writes.

## Context

- @.planning/phases/37-scale-feasibility-spike/37-CONTEXT.md (decision 2: real-data samples; default: 100k/500k/1M ladder, extrapolation labeled)
- @scripts/compute_instance_embeddings.py (lineage: psycopg via DIRECT_URL/DATABASE_URL, pacmap 0.9.1 + faiss-cpu 1.14.3 installed, deterministic seed pattern)

## Tasks

1. **Sampler** — psycopg SELECT with `TABLESAMPLE SYSTEM` (+ exact `LIMIT` top-up if the sample under-fills) pulling `userEmail, activityVerb, serviceGroup, objectType, projectId, createdAt` from `AccActivityAccds` at the requested size. Read-only.
2. **Feature builder** — rough Phase-38-shaped vector (documented as approximation): hashed one-hot buckets for author/verb/project/objectType (e.g. 16+8+16+8 dims) + cyclic month (2 dims) + recency scalar → float32 matrix ~50 dims. Deterministic hash, `random_state=42` everywhere.
3. **PaCMAP ladder** — fit at 100k, wall-clock. If projected 500k/1M runtimes stay under ~45 min each (linear-to-superlinear extrapolation from the 100k point, stated in output), run them; otherwise record the skip + reason. Peak RSS recorded per fit (resource module / psutil if present).
4. **faiss projection** — build index on the fitted sample's feature matrix, project a held-out 50k batch (k-NN weighted average of neighbor embeddings), measure rows/sec; extrapolate to the 4.86M remainder, labeled estimate.
5. **Output** — JSON `{sampleRuns:[{n, fitSeconds, peakRssMb}], projection:{rowsPerSec, estRemainderMinutes}, fullFitEstimate:{basis, estMinutes, label:"extrapolation"}}` to stdout + `scratchpad` copy; paste into 37-BASELINE.md in 37-04.

## Verification gates

- Script executes end-to-end on the workshop machine (this IS the measurement — runs in this plan, not 37-04, since it needs no server).
- Determinism spot-check: 100k fit re-run with same seed → identical embedding checksum (first 10 rows hashed).
- No DB writes: script contains no INSERT/UPDATE/CREATE.

## Success criteria

Truths hold; numbers recorded in SUMMARY for 37-04 assembly.
