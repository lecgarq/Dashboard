# Plan 37-01 — Spike render harness (SCALE-01 track a)

## Objective

Committed, flag-gated spike route that renders the full 4,862,301-point set in
cosmos.gl via the existing `GraphCanvas2D`, with a measurement bridge good enough
for a Playwright spec (37-04) to drive all four render scenarios and read
median/min fps, GPU info, and context-loss events.

## Context (@ read before executing)

- @.planning/phases/37-scale-feasibility-spike/37-CONTEXT.md (locked decisions 1–3)
- @app/(dashboard)/users/access-analysis/GraphCanvas2D.tsx (handle API; PhysicsLayer usage: `getPositions()`, `getSliders()`, `frozen`)
- @app/(dashboard)/users/access-analysis/physicsLayer.ts (interface to stub)

- @app/(dashboard)/users/access-analysis/graphTestBridge.ts (bridge style to mirror; spike gets its OWN `window.__SCALE_SPIKE__`, does not touch `__ACC_GRAPH_TEST__`)

## Tasks

1. **Discovery (read-only DB):** `SELECT COUNT(DISTINCT "activityVerb") FROM "AccActivityAccds"` (indexed column). Record the live verb cardinality; pick Uint8 vs Uint16 for the verb column from it. Also record it in the SUMMARY for 37-02/37-03 reuse. Resolves VERIFY (verb set size).
2. **`spikeSynthetic.ts`** — pure, deterministic (mulberry32 seeded): `generateSpikePositions(n, seed)` → stride-3 Float32Array Gaussian-mixture (~48 clusters, organic look, spread ≈±350 to match the frozen-path camera assumptions) and `generateSpikeAttributes(n, seed, cardinalities)` → typed-array columns (verbId, projectId Uint16 (956), authorId Uint16 (2,313), month Uint8 (60)) + RGBA Float32Array colors derived from verbId over a fixed palette. No React imports.
3. **`spikePhysicsStub.ts`** — minimal `PhysicsLayer` implementation: `frozen=true`, `getPositions()` returns the synthetic buffer, `getSliders()` `{}` , mask/slider/drag methods no-ops, `alphaMask` empty Float32Array (never read on the spike path). Cast-free if practical; a single documented `as PhysicsLayer` escape hatch acceptable for unused members.
4. **`ScaleSpikeClient.tsx`** — client component: container div (zinc background `#09090B`), mounts `GraphCanvas2D` with the stub; `?n=` query param (default 4,862,301), `?gpu=1` remount variant with `gpuSimulation:true` (weak forces → cosmos GPU-side drift = the L0 hope). Scenario runner exposed on `window.__SCALE_SPIKE__`:
   - `rest` — frozen, no pushes; sample fps ≥10 s via rAF deltas fed to `createAmbientFpsController().observeWindow` + raw median/min.
   - `panzoom` — programmatic camera oscillation via handle `restoreView`/`focusPoint` while sampling.
   - `cpuAmbient` — rAF loop writing sin/cos offsets into the stride-3 buffer then `handle.pushPositions` (the honest CPU-ceiling measurement; expected to fail the bar).
   - `gpuDrift` — only meaningful with `?gpu=1`: cosmos sim running, no CPU pushes; sample fps.
   Bridge also records: `webglcontextlost`/`restored` events (with scenario timestamp), `WEBGL_debug_renderer_info` renderer string, JS-side allocation accounting (bytes of every typed array created), `performance.memory` when present, ready timestamp, node count actually set.
5. **`page.tsx`** — server component: `process.env.NEXT_PUBLIC_ACC_SCALE_SPIKE !== "1"` → `notFound()`; else render client. One-line comment: spike surface, Phase 37, remove/re-gate decision at milestone close.
6. **`spikeSynthetic.test.ts`** — Vitest: determinism (same seed → identical first/last 12 values), shape (n*3, n*4 colors, column lengths), bounds (positions finite, within expected spread; column values < cardinality).
