**Step B — Create useGraphRafLoop.ts:**

A custom React hook that drives a single requestAnimationFrame loop. Signature:

```typescript
export function useGraphRafLoop(opts: {
  physics: PhysicsLayer;
  mode: '2d' | '3d';
  enabled: boolean;
  onTick2D: (xyz: Float32Array) => void;   // called when mode === '2d'
  onTick3D: (xyz: Float32Array) => void;   // called when mode === '3d'
  onMaskChange?: (alphaMask: Float32Array, version: number) => void;
}): void;
```

Behavior:
- One useEffect; cancels prior rAF on cleanup or dep change.
- Each frame: call `physics.getPositions()` ONCE per frame; route to onTick2D OR onTick3D based on mode.
- Track `lastMaskVersion` in a useRef. After each tick, if `physics.maskVersion !== lastMaskVersion`, fire `onMaskChange(physics.alphaMask, physics.maskVersion)` and update the ref.
- DO NOT allocate Float32Arrays inside the loop. The xyz Float32Array reference comes from physicsLayer (each call allocates, per physicsLayer.ts source — Pitfall 4 in RESEARCH); pass it through directly without copying.
- DO NOT call `physics.alphaMask` every frame; only inside the maskVersion-guarded branch.
- `enabled: false` → cancelAnimationFrame and do not schedule.

**Step C — Create GraphCanvas.tsx:**

The public component. Owns the two canvas containers (one for 2D, one for 3D) absolutely positioned in the same outer div. Wires the rAF loop and renders GraphCanvas2D + a placeholder div for 3D (Plan 03-02 fills the 3D slot).

```tsx
'use client';

import { useRef } from 'react';
import { useTheme } from 'next-themes';
import type { PhysicsLayer } from './physicsLayer';
import { GraphCanvas2D, type GraphCanvas2DHandle } from './GraphCanvas2D';
import { useGraphRafLoop } from './useGraphRafLoop';

export interface GraphCanvasProps {
  physics: PhysicsLayer;
  nodeColors: Float32Array;
  nodeSizes?: Float32Array;
  mode: '2d' | '3d';
  activeDimNames?: readonly string[];
  hoveredIndex?: number;
  selectedIndices?: readonly number[];
  backgroundColor?: string;
  width?: number;   // optional; defaults to container clientWidth
  height?: number;
}

export function GraphCanvas(props: GraphCanvasProps): JSX.Element {
  const { resolvedTheme } = useTheme();
  const bg = props.backgroundColor ?? (resolvedTheme === 'dark' ? '#09090B' : '#FFFFFF');

  const handle2D = useRef<GraphCanvas2DHandle | null>(null);
  const container2DRef = useRef<HTMLDivElement | null>(null);
  const container3DRef = useRef<HTMLDivElement | null>(null);

  useGraphRafLoop({
    physics: props.physics,
    mode: props.mode,
    enabled: true,
    onTick2D: (xyz) => handle2D.current?.pushPositions(xyz),
    onTick3D: () => {
      // Plan 03-02 wires this to GraphCanvas3D handle
    },
    onMaskChange: (mask, version) => {
      handle2D.current?.applyAlphaMask(mask, version);
    },
  });

  return (
    <div style={{ position: 'relative', width: '100%', height: '100%' }}>
      <div
        ref={container2DRef}
        style={{
          position: 'absolute',
          inset: 0,
          visibility: props.mode === '2d' ? 'visible' : 'hidden',
        }}
      >
        <GraphCanvas2D
          containerRef={container2DRef}
          physics={props.physics}
          nodeColors={props.nodeColors}
          nodeSizes={props.nodeSizes}
          backgroundColor={bg}
          onHandleReady={(h) => { handle2D.current = h; }}
        />
      </div>
      <div
        ref={container3DRef}
        style={{
          position: 'absolute',
          inset: 0,
          visibility: props.mode === '3d' ? 'visible' : 'hidden',
        }}
      >
        {/* Plan 03-02 mounts GraphCanvas3D here */}
      </div>
    </div>
  );
}
```

**Implementation requirements (verbatim from RESEARCH patterns):**

1. **Construct Graph in a useEffect** (mount-only, deps `[]`):
   ```typescript
   const graph = new Graph(props.containerRef.current!, {
     enableSimulation: false,         // CRITICAL — Pattern 1, Pitfall 1
     transitionDuration: 0,           // CRITICAL — Pitfall 4 (no GPU tweens during rAF push)
     renderLinks: false,              // CONTEXT.md locked: zero edges
     backgroundColor: props.backgroundColor,
     pointGreyoutOpacity: 0.15,       // matches DIM_ALPHA in CosmosCanvasClient.ts
     spaceSize: 4096,
     fitViewOnInit: true,
     fitViewDelay: 250,
     fitViewPadding: 0.1,
     pixelRatio: window.devicePixelRatio,
   });
   ```

2. **Initial data load** (after construct, before exposing handle):
   - Get initial positions via `props.physics.getPositions()` (stride-3, n*3).
   - Allocate a persistent stride-2 buffer: `const xy2 = new Float32Array(n * 2);` — this buffer is REUSED on every tick (Pitfall 4). Stored in a useRef.
   - Downproject xyz → xy2 (drop z).
   - Call `graph.setPointPositions(xy2, false)` (false = rescale on first frame so fitView works).
   - Call `graph.setPointColors(props.nodeColors)` (RGBA Float32Array(n*4)).
   - If `props.nodeSizes` provided: `graph.setPointSizes(props.nodeSizes)`.
   - Call `graph.render()`.

3. **Expose the handle via onHandleReady:**
   ```typescript
   props.onHandleReady({
     pushPositions(xyz) {
       const n = xyz.length / 3;
       for (let i = 0; i < n; i++) {
         xy2[i * 2]     = xyz[i * 3];
         xy2[i * 2 + 1] = xyz[i * 3 + 1];
       }
       graph.setPointPositions(xy2, true); // dontRescale=true on tick updates (Pitfall 2)
       graph.render();
     },
     applyAlphaMask(mask, _version) {
       const lit: number[] = [];
       for (let i = 0; i < mask.length; i++) {
         if (mask[i] >= 0.99) lit.push(i);
       }
       const allLit = lit.length === mask.length;
       graph.setConfigPartial({
         highlightedPointIndices: allLit ? undefined : (lit as unknown as number[]),
       });
       graph.render();
     },
     setColors(rgba) {
       graph.setPointColors(rgba);
       graph.render();
     },
   });
   ```

4. **Cleanup on unmount:** `graph.destroy?.()` then null out refs.

5. **Background color reactivity:** A second useEffect with dep `[props.backgroundColor]` calls `graph.setConfigPartial({ backgroundColor: props.backgroundColor })`. NEVER use `graph.setConfig` (Pitfall 1: resets all defaults including enableSimulation).

6. **Color/size updates:** useEffects with deps `[props.nodeColors]` and `[props.nodeSizes]` call the handle methods.

**Returns null** — the component owns no DOM; it attaches cosmos.gl to the parent's container ref.

**Async-readiness guard (Pitfall 3):** Wrap the construct + initial data calls in:
```typescript
let cancelled = false;
let g: Graph | null = null;
(async () => {
  g = new Graph(div, config);
  // some cosmos.gl v3 builds expose graph.ready as a Promise; if present, await it:
  if ((g as any).ready instanceof Promise) await (g as any).ready;
  if (cancelled) { g.destroy?.(); return; }
  // ...initial data load + handle exposure
})();
return () => { cancelled = true; g?.destroy?.(); };
```

**REND-05 smoothness:** Verified by (a) `transitionDuration: 0` (no GPU tweens), (b) `dontRescale: true` on per-tick setPointPositions (no coordinate jitter), (c) single shared xy2 buffer (no per-frame allocation). No additional render-side tweening.
