APS endpoints:
- Members:  GET /construction/admin/v1/projects/{projectId}/users?limit=100&offset={n}&fields={MEMBER_FIELDS}
  - projectId = bare UUID (no b. prefix)
  - MEMBER_FIELDS = "name,email,status,companyName,phone,addedOn,lastSignIn,accessLevels,products,roles,autodeskId"
  - Response: { results: RawMember[] } — paginated with results.length < limit sentinel.
- Per-project roles: GET /hq/v2/accounts/{accountId}/projects/{projectId}/industry_roles
  - Plain array response. Use fetchHqUsers helper.
  - Each role: { id, name, services?: { document_management?: { access_level }, project_administration?: { access_level } } }

Plan 02-04 consumes an in-memory map produced by this plan. The contract is:

```typescript
export interface MemberAggregatorEntry {
  email: string;                               // lowercased
  autodeskId: string;
  name: string;
  // per-project occurrences, deduped by projectId:
  perProject: Array<{
    projectId: string;
    projectName: string;
    status: string;
    projectAdmin: boolean;
    executive: boolean;
    products: Record<string, ProductTier>;     // normalized
    roleNames: string[];                       // raw names from /users response
    addedOn: string | null;                    // ISO
    lastSignIn: string | null;                 // ISO
    companyName: string | null;
    phone: string | null;
  }>;
}
export type MemberAggregator = Map<string, MemberAggregatorEntry>;  // key = lowercased email
```

`extractAndPersistProjectData` MUST take a `MemberAggregator` parameter and APPEND each member's per-project record to the entry (creating the entry on first sight). Plan 02-04 reads this map at the end and writes accMemberCache.

3. `export async function extractAndPersistProjectData(prisma, accountId, project, accessToken, aggregator): Promise<void>`:
   - **Step A** — fetch per-project roles BEFORE members (per Pitfall 3):
     ```typescript
     const projectRoles = await fetchProjectRoles(accountId, project.id, accessToken);
     ```
   - **Step A.1** — upsert AccRole rows for any project-roles not already present (per-project roles may include hub roles, but also project-only ones). Use `prisma.accRole.upsert({ where: { id }, create: { id, accountId, name, memberCount: 0, syncedAt: now }, update: { name, syncedAt: now } })` for each.
   - **Step A.2** — build `const roleNameToId = new Map(projectRoles.map(r => [r.name.toLowerCase(), r]));`
   - **Step A.3** — upsert "unassigned" AccProjectRole rows (one per project-role, memberId=null) so default access levels are persisted even when no member is linked yet:
     ```typescript
     for (const role of projectRoles) {
       await prisma.accProjectRole.upsert({
         where: { projectId_roleId_memberId: { projectId: project.id, roleId: role.id, memberId: null } },
         create: { projectId: project.id, roleId: role.id, memberId: null, docsAccessLevel: role.docsAccessLevel, projectAdminAccessLevel: role.projectAdminAccessLevel },
         update: { docsAccessLevel: role.docsAccessLevel, projectAdminAccessLevel: role.projectAdminAccessLevel },
       });
     }
     ```
     Note: Prisma's `@@unique([projectId, roleId, memberId])` treats NULL as distinct; verify the upsert compound key works. If Prisma rejects null in the compound where, fall back to `findFirst + create-or-update` pattern.

   - **Step B** — fetch members:
     ```typescript
     const { members, lastSignInPresent } = await fetchProjectMembers(project.id, accessToken);
     if (!lastSignInPresent && members.length > 0) {
       console.warn(`[quick-sync] project ${project.id}: lastSignIn field absent from response — ?fields= may have been dropped`);
     }
     ```

   - **Step C** — for each `raw` member:
     a. Compute fields: `email = raw.email.toLowerCase()`, `name = raw.name`, `autodeskId = raw.autodeskId`, `status = raw.status`, `companyName = raw.companyName ?? null`, `phone = raw.phone?.number ?? null` (object → flattened string), `addedOn = raw.addedOn ? new Date(raw.addedOn) : null`, `lastSignIn = raw.lastSignIn ? new Date(raw.lastSignIn) : null`, `projectAdmin = raw.accessLevels?.projectAdmin ?? false`, `executive = raw.accessLevels?.executive ?? false`, `products = normalizeProducts(raw.products)`.
     b. Upsert AccProjectMember:
        ```typescript
        const saved = await prisma.accProjectMember.upsert({
          where: { projectId_autodeskId: { projectId: project.id, autodeskId } },
          create: { projectId: project.id, autodeskId, email, name, status, companyName, phone, addedOn, lastSignIn, projectAdmin, executive, products, syncedAt: new Date() },
          update: { email, name, status, companyName, phone, addedOn, lastSignIn, projectAdmin, executive, products, syncedAt: new Date() },
        });
        ```
     c. For each `raw.roles ?? []`: resolve name → role via `roleNameToId.get(roleName.toLowerCase())`. If found, upsert AccProjectRole with `memberId = saved.id` and the role's default access levels. If not found, `console.warn` with project ID + role name (do NOT throw).
     d. Append to aggregator:
        ```typescript
        let entry = aggregator.get(email);
        if (!entry) { entry = { email, autodeskId, name, perProject: [] }; aggregator.set(email, entry); }
        entry.perProject.push({
          projectId: project.id,
          projectName: project.name,
          status, projectAdmin, executive, products,
          roleNames: (raw.roles ?? []).map(r => r.name),
          addedOn: addedOn?.toISOString() ?? null,
          lastSignIn: lastSignIn?.toISOString() ?? null,
          companyName, phone,
        });
        ```

   - Log summary: `[quick-sync] project ${project.id} (${project.name}): ${members.length} members, ${projectRoles.length} roles`.

4. `export async function runPerProjectFanOut(prisma, accountId, projects, accessToken): Promise<{ aggregator: MemberAggregator; failCount: number; failures: Array<{ projectId: string; error: string }> }>`:

   - `const limit = pLimit(5);`
   - `const failures: Array<{ projectId: string; error: string }> = [];`
   - `await Promise.all(projects.map(p => limit(async () => { try { await extractAndPersistProjectData(prisma, accountId, p, accessToken, aggregator); } catch (err) { const msg = err instanceof Error ? err.message : String(err); console.warn(`[quick-sync] project ${p.id} failed:`, msg); failures.push({ projectId: p.id, error: msg }); } })));`
   - Return `{ aggregator, failCount: failures.length, failures }`.
   - This implements **skip-and-continue** per RESEARCH.md Decision 1 (matches v1.0 bulkAccSync pattern).
