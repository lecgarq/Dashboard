All four files export `default` GLSL string sources.

nodeRender.vert:
- attributes: `aNodeIndex` (float), `aVisible` (float 0..1 — lerped CPU-side toward target), `aColor` (vec3), `aGlow` (float — 0..1 derived from isAdmin/lastSignIn).
- uniforms: `uPositionTexture`, `uTextureWidth`.
- texelFetch position; project; `gl_PointSize = clamp(150.0 / -mv.z, 2.0, 24.0) * aVisible`; varyings vColor + vGlow + vVisible.

nodeRender.frag:
- gl_PointCoord-based circular discard (length(uv - 0.5) > 0.5 → discard).
- Center-bright + edge-darken: `intensity = (1.0 - length(uv - 0.5) * 2.0)`.
- Glow boost: `color = vColor * (0.8 + intensity * 0.6) + vec3(vGlow) * 0.4`.
- Alpha = `vVisible * intensity`.
- `gl_FragColor = vec4(color, alpha)`.

edgeRender.vert:
- attributes: `aEndpointIndex` (float), `aEdgeAlphaBase` (float — set once on filter change).
- uniforms: `uPositionTexture`, `uTextureWidth`, `uHighlightedNodeIndex` (float; -1 if none), `uHighlightMul` (float, default 4.0).
- read position by texelFetch; project; varyings vAlpha = aEdgeAlphaBase * (aEndpointIndex == uHighlightedNodeIndex ? uHighlightMul : 1.0); vDepth = mv.z.

edgeRender.frag:
- depthFade = clamp((vDepth + uFarFade) / uFarFade, 0.1, 1.0) // closer = brighter
- gl_FragColor = vec4(uEdgeColor, vAlpha * depthFade * uBaseEdgeAlpha).

Tune defaults: uBaseEdgeAlpha = 0.08 (very faded by default per CONTEXT "all edges drawn at very low opacity").

Create `NodesPoints.tsx` ("use client"):
- Props: `{ nodes: AccGraphInstanceNode[]; physics: PhysicsApi; visibility: Uint8Array; visibilityVersion: number; highlightedIndex: number | null; onClick?: (index: number) => void }`.
- Build a `THREE.BufferGeometry` once: `aNodeIndex` (Float32Array 0..n-1), `aColor` (from node.color hex parse), `aGlow` (derive from isAdmin/lastSignIn), `aVisible` (initialized to visibility[i]).
- Build a `THREE.ShaderMaterial` with `transparent: true, depthWrite: false, blending: THREE.AdditiveBlending` and the node shader sources.
- On each frame in `useFrame`: lerp current `aVisible` values toward `visibility[i]` at rate `dt * 5.0` (smooth filter reflow alpha — RESEARCH Pattern: do NOT rebuild the buffer; just write into the existing Float32Array and set `needsUpdate = true`).
- Update uniform `uPositionTexture = physics.getPositionTexture()` each frame.
- Render `<points geometry={geo} material={mat} />`.
- Hover-via-pointer is NOT done here (deferred to picking in Plan 06-06). Pass `onClick` straight through — Plan 06-06 supplies the picked index.

Create `EdgesLines.tsx` ("use client"):
- Props: `{ physics: PhysicsApi; edgeBuffers: ReturnType<typeof buildEdgeBuffers>; highlightedNodeIndex: number | null; visibility: Uint8Array; visibilityVersion: number }`.
- Build `THREE.BufferGeometry` once: 2 endpoints per edge slot → `aEndpointIndex` (Float32Array length `totalEdgeSlots * 2`, pattern [src,dst,src,dst,...]) + `aEdgeAlphaBase` (Float32Array length `totalEdgeSlots * 2`).
- Use `THREE.LineSegments` (drawMode lines).
- On `visibilityVersion` change: walk slots, write `aEdgeAlphaBase[2k] = aEdgeAlphaBase[2k+1] = (visible[src] && visible[dst]) ? 1.0 : 0.0`, mark `needsUpdate`.
- Uniforms: `uHighlightedNodeIndex = highlightedNodeIndex ?? -1`, `uHighlightMul = 6.0`, `uPositionTexture = physics.getPositionTexture()`, `uFarFade = 80.0`, `uBaseEdgeAlpha = 0.08`, `uEdgeColor = vec3(0.7, 0.85, 1.0)`.
- `transparent: true, depthWrite: false, blending: AdditiveBlending`.

NEITHER component reads the position texture on CPU — all positions live on GPU, period.
