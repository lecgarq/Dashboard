  <what-built>
Phase 2 Content Blocks: collaborative tables with sort/filter/color/export/sticky header, inline PDF viewer from Google Drive with right-click Replace PDF + Edit link, enhanced image blocks with alignment/lightbox/caption/Replace media, enhanced video blocks with alignment/caption/Replace media, upload progress bar, and block insertion UX (slash menu + drag handles).
  </what-built>
  <how-to-verify>
Open the wiki editor in your browser at http://localhost:3000 and run through these checks:

**1. Slash Menu**
- Click in the editor and type `/`
- Confirm: slash menu opens with icon + label items
- Type "tab" — confirm table result appears (fuzzy search works)
- Press Escape to dismiss

**2. Table Block**
- Type `/` → select Table → confirm a 3x3 table with header row inserts
- Click in cells and type — confirm Tab advances to next cell
- Tab from last cell — confirm a new row is added
- Hover over row/column edges — confirm `+` buttons appear for adding rows/columns
- Right-click a cell — confirm options for text alignment, background color, and cell merge
- Set a cell background color to red — confirm it saves and shows red
- Click a column header — confirm rows sort ascending; click again for descending
- **Scroll through a long table (add 15+ rows) — confirm the header row stays frozen at top (sticky)**
- **Copy 3 cells from Google Sheets or Excel and paste into the editor — confirm a formatted table appears**
- Right-click the table — confirm "Export as .xlsx" option; click it and confirm an .xlsx file downloads
- Open the same page in a second tab — confirm table edits sync in real time

**3. PDF Block**
- Type `/` → select PDF → upload a PDF file from Google Drive (or paste a Drive URL)
- Confirm: filename label appears above viewer, PDF pages render inline
- Confirm: toolbar shows zoom, page navigation, download button
- Drag the bottom edge — confirm viewer height resizes
- Click download button — confirm PDF downloads
- **Right-click the PDF viewer — confirm "Replace PDF" and "Edit link" options appear**
- Click "Edit link" — confirm inline panel appears, enter a different Drive URL, confirm PDF updates

**4. Image Block**
- Upload an image via `/` → Image or paste an image
- **Confirm: upload progress bar appears with filename during upload, then disappears when done**
- Confirm: image renders at full-width by default
- Click the image when selected — confirm alignment toolbar appears (Left / Center / Right / Full-width)
- Switch to Center alignment — confirm image centers horizontally
- Click the image — confirm lightbox opens full-screen
- Press X or click outside lightbox — confirm it closes
- Right-click the image — confirm "Replace media" and "Copy link" options appear
- Click "Replace media" — confirm file picker opens, select a new image, confirm image swaps in place (block not deleted)

**5. GIF Block**
- Upload a GIF file
- Confirm: GIF autoplays on load (animates without clicking)

**6. Video Block**
- Upload a video file
- Confirm: video renders with alignment toolbar and caption field matching image behavior
- Right-click the video — confirm "Replace media" option swaps the video file without deleting the block

**7. Drag Handle**
- Hover over any block (paragraph, table, image) — confirm drag handle appears on left
- Confirm `+` button also appears on hover
- Drag a block to a new position — confirm document reorders correctly

**8. Collaboration Sync**
- Open the wiki in two browser tabs simultaneously
- In Tab 1: insert a table, type in a cell
- In Tab 2: confirm the table and text appear in real time
