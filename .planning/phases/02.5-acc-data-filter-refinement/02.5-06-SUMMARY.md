## Visual changes shipped

All in `app/(dashboard)/users/AccUsersGraph.tsx`. Behavior/logic unchanged.

### `ModuleToggle` (~line 2126)

- Adjacent `ON`/`OFF` text label (emerald-600 for ON, gray-400 for OFF), 6 chars wide so layout doesn't shift on toggle
- OFF state strengthened: switch background `bg-gray-300` (was `bg-gray-200`), knob `bg-gray-50` (was `bg-white`)
- Disabled module label rendered with `text-gray-400 line-through` so it's obvious at a glance which modules are excluded
- Preserves `role="switch"` + `aria-checked`

### `CompanyRoleFilter` (~line 2149)

- Trigger button shows "All roles" (or "N role(s) selected") + chevron `▾` that rotates 180° when open
- Floating panel `absolute left-0 right-0 top-full z-20` with shadow + border + rounded corners
- `useEffect` attaches `mousedown` + `keydown` listeners while `open === true`; click-outside or Escape closes
- Selecting a role does NOT auto-close — multi-select stays open until explicit dismiss
- Search input retains autofocus when panel opens
- Container uses `relative` positioning so the panel anchors under the trigger

### Filter panel header

- "Showing X of Y users" promoted to its own line as an emerald badge: `inline-flex items-center gap-1 px-2 py-1 rounded-md bg-emerald-50 text-emerald-700 text-[11px] font-semibold`, with the X bolded inside
- "Clear all" promoted from text-link to bordered button: `border border-gray-300 bg-white hover:bg-gray-100 hover:border-gray-400`, prefixed with `×` glyph

### Empty-state overlay (~line 1733)

- Magnifier glyph `🔍` above the title
- Title `text-base font-semibold text-gray-800` (was `text-sm font-medium text-gray-700`)
- Subtitle `text-sm text-gray-500` reads "Try adjusting your filters to see results"
- "Clear filters" CTA upgraded to primary button: `px-4 py-2 rounded-lg bg-gray-900 text-white text-sm font-semibold shadow-sm`
- Background opacity bumped to `bg-[#F8F7F4]/95` for stronger separation from the canvas
