**Part A — CompanyRoleFilter (dropdown):**

Rewrite the `CompanyRoleFilter` sub-component (~line 2141) to render as a dropdown:

1. Add local state: `const [open, setOpen] = useState(false);` and `const [search, setSearch] = useState("");` (preserve existing search).
2. Render a trigger button that always shows: either "All roles" (when `selected.length === 0`) or `${selected.length} role(s) selected`. Style it as a full-width button matching existing filter controls — `border border-gray-200 rounded-lg px-2 py-1.5 text-[11px] flex items-center justify-between bg-white hover:bg-gray-50`. Include a chevron-down icon (use a simple unicode `▾` or an inline SVG ~12px).
3. When `open` is true, render a floating panel (absolute positioned, `z-20`, `mt-1`, `border border-gray-200 rounded-lg bg-white shadow-lg p-2`) anchored under the trigger. The panel contains the existing search input + filtered option list (max-h-48, overflow-y-auto).
4. Click-outside dismiss: use a `useEffect` that attaches a `mousedown` listener to `document` and closes when the click target is outside the dropdown's containing ref. Standard pattern — wrap the trigger + panel in a `<div ref={containerRef} className="relative">`.
5. Press Escape closes the dropdown.
6. Selecting an option does NOT auto-close — user can multi-select. Closing happens via outside click, Escape, or clicking the trigger again.

**Part B — ModuleToggle (clearer ON/OFF):**

Rewrite the `ModuleToggle` sub-component (~line 2118) to make ON/OFF unambiguous:

1. Keep the iOS-style switch but ALSO render an explicit `ON` / `OFF` text label adjacent to the switch (right-aligned, `text-[9px] font-semibold` using `text-emerald-600` for ON and `text-gray-400` for OFF).
2. Strengthen the OFF state visually: change OFF background from `bg-gray-200` to `bg-gray-300` and the knob to `bg-gray-50` for higher contrast.
3. Optional reinforcement: when OFF, render the module label in `text-gray-400 line-through`; when ON, `text-gray-700`. (Improves at-a-glance readability of which modules are excluded.)
4. Preserve `role="switch"` and `aria-checked={enabled}` for accessibility.

After both changes:
