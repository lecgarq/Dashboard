## What Was Built

### Filter panel additions (AccUsersGraph.tsx)

**Date range (FILT-02):**
- Two native `<input type="date">` fields labeled "From" and "To"
- Bound to `filters.dateFrom` and `filters.dateTo` (YYYY-MM-DD strings)
- Section label: "Last Activity" (maps to `lastSignIn` field)
- **Note:** `lastSignIn` field names not yet verified live against ACC API. If the 02.5-01 diagnostic log (fired on next sync) confirms the field is unavailable/always-null, the label should be updated to "Added Date" to reflect the fallback to `addedOn`

**Module toggles (FILT-03):**
- New `ModuleToggle` sub-component: `button[role="switch"]` with iOS-style Tailwind animation
- One toggle per module from `filterOptions.moduleOptions`
- `enabled` = NOT in `filters.disabledModules` (exclude-list semantics — all ON by default)
- Section hint text: "Toggle off to filter users with access only to that module."

**companyRole multi-select (DATA-01):**
- New `CompanyRoleFilter` sub-component with local `search` state
- Search box filters options with `String.includes` (case-insensitive)
- Scrollable option list (max-h-36); each option shows label + count
- Active options show inverted (dark background) — matches existing FilterMenu chip style
- "Unspecified" bucket appears for users with null companyRole

**Filter panel header:**
- "Showing X of Y users" text (emerald) renders when `activeFilterCount > 0`
- "Clear all" button (top-right) visible only when `activeFilterCount > 0`; calls `setFilters(DEFAULT_FILTERS)`

**Empty-state overlay:**
- Renders when `isReady && visibleCount === 0 && hasActiveFilters`
- Positioned at `z-30` — above fade wrapper, below cosmos loading overlay (z-40) and HUD (z-50)
- Message: "No users match these filters" + "Adjust filters to see results"
- "Clear filters" button calls `setFilters(DEFAULT_FILTERS)` (same handler as panel Clear all button)
