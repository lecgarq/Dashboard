<objective>
Close OBS-01: make ACCDS session expiry visible BEFORE a crawl fails, on two
operator surfaces — (a) the `scripts/accds-activity-ingest.cjs` crawler as a
startup `[WARN]` preflight, and (b) the `localhost:4321` progress monitor as an
always-on session-health status line.

Purpose: a dead/near-dead ACCDS web session is fatal to an entire crawl run and
re-login is cheap. Today the only signal is a fatal `SessionExpiredError` thrown
mid-run once the token provider is first used. This plan gives the operator a
clear heads-up before kicking off a long crawl, and an at-a-glance "is my session
good right now?" indicator on the monitor.

Output: a shared `getSessionHealth(sessionPath)` helper (local file read, no
Autodesk call), a crawl-side preflight WARN, and a monitor health line — all
honoring the locked < 12h threshold and the estimate-labeling rule.
</objective>

    hoursRemaining: number | null, estimate: boolean, cookieCount: number, message: string }`;
    and an exported async `getSessionHealth(sessionPath: string): Promise<SessionHealth>`.
