# 38-02 — Full-corpus activity embedding pipeline (EMB-07)

## Objective

`scripts/compute_activity_embeddings.py` reads the unified activity corpus straight
from PostgreSQL, builds the hybrid author+event feature matrix, full-fit PaCMAPs the
whole corpus (owner decision 1), proves determinism twice, runs the quality gate, and
COPY-loads positions + dictionary-coded attributes into `AccActivityEmbedding`.
Dictionaries persisted for 38-03. Old instance pipeline untouched.

## Tasks

### Task 1 — corpus read + dictionaries + feature matrix (pure fns + I/O)

- SQL (psycopg, server-side cursor / chunked fetch) selecting per event:
  source-prefixed id, emailLower, projectId, activityVerb/rawAction, serviceGroup,
  objectType, folderId, createdAt. Unified semantics per `UNIFIED_ACTIVITY_CTE`
  (accds full; `AccActivity` backfill = createdAt < per-project accds start OR
  projectId NULL; admin rows included). Assert total == fresh
  `countUnifiedActivityRows`-equivalent SQL count (recorded).
- Build dictionaries (deterministic, sorted): verb, objectType, project, author
  (emailLower; index 0 = "Unknown author"), role (0=Unknown), company (0=Unknown),
  folder (0=none), month (months since corpus MIN(createdAt)). Module code via the
  verb→module classification: replicate the `classifyActivity` verb mapping ONLY if
  trivially portable — otherwise moduleId = serviceGroup dictionary code and record
  the deviation (module classification is re-derivable client-side in Phase 39/40
  from verbId; do NOT fork a divergent copy of `activityClassification.ts` logic).
- Join author attributes from `.embedding/activity-author-attributes.json`
  (38-01 sidecar) on (emailLower, projectId), falling back to Unknown codes.
- Feature matrix float32, hashed/one-hot blocks (spike lineage, dims bounded ~80):
  author 16 / verb 8 / project 16 / objectType 8 / folder 8 / role 4 / company 4 /
  modules multi-hot-hashed 4 + cyclic month 2 + recency scalar 1.
- Persist dictionaries to `.embedding/activity-universe-dicts.json` (verb/objectType/
  project/author/role/company/month labels; NO folder-name dictionary — ints only).

### Task 2 — full fit, determinism, gate, write

- Full-fit PaCMAP (n_components=2, angular, `random_state=42`, apply_pca=False,
  numpy float32 input; no SVD densification — matrix is already dense-narrow).
- Record wall-clock + peak RSS. **Fallback clause (armed, owner decision 1):** if
  fit exceeds 90 min or RSS 12 GB, abort with recorded numbers — do NOT write;
  pivot decision goes back to the owner with an IVF/HNSW benchmark first.
- Determinism: run the fit a second time (fresh process or fresh model object),
  byte-compare coords (`np.array_equal`) — mismatch aborts before write.
- Quality gate before write: finite-coords assert; trustworthiness(k=10) on a
  bounded subsample (TRUST_SAMPLE lineage) recorded to
  `.embedding/activity-embedding-gate.json` as the stored baseline; on future
  reruns compare vs stored baseline (EMB-05 discipline) — regression aborts.
- Write path: normalize coords (HALF_EXTENT lineage), then single transaction:
  `TRUNCATE "AccActivityEmbedding"` + psycopg `COPY` (not per-row INSERT — 4.9M).
  embeddingRunId = timestamp+uuid (compute_instance lineage). Post-write assert:
  `SELECT COUNT(*)` == corpus count, printed.

### Task 3 — pytest for pure functions

- `scripts/test_compute_activity_embeddings.py`: hashed-block determinism (same
  input → same columns), month/recency encoding, unified-boundary row filter pure
  helper, Unknown-code fallbacks (null email → authorId 0). Run:
  `python -m pytest scripts/test_compute_activity_embeddings.py -q`.
