# 38-03 — Binary payload artifact, route, budget gate, staleness wiring (SCALE-02)

## Objective

The pipeline output becomes a servable binary artifact; a production route streams it
inside the measured budget; ingest gains the non-fatal staleness signal. The graph
still renders the old universe — no UI change (Phase 39 consumes this route).

## Tasks

### Task 1 — payload builder script + shared reader

- `lib/server/activityUniversePayload.ts`: server-shared module owning
  - artifact paths (`.embedding/activity-universe.bin`, `activity-universe-meta.json`),
  - `readActivityUniverseMeta()` (parsed meta or null),
  - pure `assembleActivityUniverseMeta(dicts, coverage, runId, count)`.
- `scripts/build-activity-universe-payload.ts` (env/adapter lineage of
  `build-instance-features.ts`): stream `AccActivityEmbedding` in chunks (raw SQL
  `ORDER BY id` keyset pagination — never one 4.9M findMany), fill typed arrays
  (positions f32 interleaved x,y; u16 for smallint codes; u32 for
  projectId/authorId/folderId), `encodeColumnarPayload` (import the scale-spike
  codec — reuse, no fork), write `.bin` + meta JSON (runId, count, dicts from
  `.embedding/activity-universe-dicts.json`, coverage from
  `.embedding/activity-author-coverage.json`). Print byte size.
- Focused vitest `lib/server/activityUniversePayload.test.ts`: meta assembly pure fn
  (coverage + dicts + runId round-trip; missing-artifact → null).

### Task 2 — production route

- `app/api/activity-universe/payload/route.ts`:
  - `GET` streams the `.bin` (Node `fs` read → Response ArrayBuffer/stream),
    `Content-Type: application/octet-stream`, `ETag: "<embeddingRunId>"`,
    `Cache-Control: public, max-age=0, must-revalidate` + 304 on `If-None-Match`
    (artifact swaps on manual pipeline reruns — revalidation keyed by run id).
  - `GET ?meta=1` (or `/meta` sibling route — pick one, record) returns the meta JSON.
  - Honest 404 with a JSON reason when the artifact is absent (no fake empty payload).
  - Auth posture: same as existing data routes (`sim-updates`, `health` — no session
    gate on this local single-user dashboard); no flag gating (this is the real route).
- Gates: tsc, repo-map check (new route).

### Task 3 — ingest staleness signal (non-fatal)

- In `scripts/dc-daily-ingest.cjs` success branch (after the instance-embedding
  block, same try/catch non-fatal shape): SQL count of unified events with
  `createdAt` > the artifact meta's run watermark (use max `AccActivityEmbedding
  .updatedAt` or meta runId timestamp; pick the cheap correct one, record) that have
  no `AccActivityEmbedding` row; log
  `[activity-universe] N new events without positions — manual pipeline run needed`.
  Skip silently (single log line) when the table is empty/absent-artifact.
  Never affects exit status.
- Gate: node syntax check (`node --check scripts/dc-daily-ingest.cjs`).

### Task 4 — budget measurement (median-of-5, :3100)

- `tests/e2e/activity-payload.spec.ts`: against the isolated `:3100` production
  build (PowerShell isolated-build lineage of `measure-scale-spike.cjs`), fetch the
  real route 5× in the browser context, per run record wire bytes, fetch ms, decode
  ms (`decodeColumnarPayload`), header-count === meta count. Assert median total
  ≤ 2,500 ms. GPU-upload is NOT re-measured here (upload was measured in 37 track (b);
  full time-to-graph re-lands in Phase 39/41 when the graph consumes the route) —
  record this scoping honestly in the summary.
- Run median-of-5; record all 5 runs + median in 38-03-SUMMARY.md.
