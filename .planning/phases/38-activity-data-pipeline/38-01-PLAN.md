## Tasks

### Task 1 — `AccActivityEmbedding` model + raw-SQL migration

- Add to `prisma/schema.prisma` (beside `AccInstanceEmbedding`):
  ```prisma
  model AccActivityEmbedding {
    id             String   @id            // "a:"+accdsActivityId | "d:"+AccActivity.id (two ID spaces)
    x              Float    @db.Real
    y              Float    @db.Real
    verbId         Int      @db.SmallInt
    objectTypeId   Int      @db.SmallInt
    moduleId       Int      @db.SmallInt   // serviceGroup/module classification code
    monthId        Int      @db.SmallInt   // months since corpus floor
    roleId         Int      @db.SmallInt   // author role (mergeRoleNames), 0 = Unknown
    companyId      Int      @db.SmallInt   // 0 = Unknown
    projectId      Int
    authorId       Int                     // 0 = Unknown author (ACT-02 explicit grouping)
    folderId       Int                     // 0 = none
    embeddingRunId String
    updatedAt      DateTime @default(now())
  }
  ```
  No relations, no extra indexes beyond PK (payload builder reads full-table scan;
  4.9M rows). VERIFY at execution: SmallInt bounds vs live cardinalities (verbs 57,
  objectTypes 13, roles/companies small; months < 200) — widen to Int where measured
  cardinality demands.
- Write `prisma/migrations/20260721000000_add_acc_activity_embedding/migration.sql`
  with the equivalent `CREATE TABLE IF NOT EXISTS` raw SQL.
- Apply via `scripts/create-activity-embedding-table.ts` (clone of
  `create-instance-embedding-table.ts`, pointing at the new SQL file), then register:
  `npx prisma migrate resolve --applied 20260721000000_add_acc_activity_embedding`.
  NEVER `prisma migrate dev` (pgvector shadow-DB trap).
- Gates: `npx tsc --noEmit`; `npx prisma migrate status` shows the migration applied;
  `node scripts/repo-map/check.cjs` (Prisma change).

### Task 3 — sidecar export + author-coverage measurement script

- `scripts/build-activity-author-attributes.ts` (lineage: `build-instance-features.ts`
