# 40-01 — Activity dimension model, organic group layout, color-by (pure)

## Objective

The pure data layer for DIM-07: 8 activity-native dimension descriptors with
honest coverage, deterministic organic category layouts (targets + label
stats), and color-by buffers for any dim. No React, no cosmos — everything
vitest-testable.

## Tasks

1. **`activityDimensions.ts`** — `ActivityDimension` descriptor: `{id, label,
   column (keyof columns), dict key, cardinality, groupBy: boolean, hasSentinel:
   boolean}`. Build the 8-dim list from a payload's meta dicts (month's labels
   generated from monthFloor + monthCount via the existing monthLabel helper).
   `author.groupBy === false`; all others true. `dimensionCoverage(columns,
   dim)`: one pass over the dim's Uint16Array counting nonzero when
   hasSentinel, else full count; returns `{covered, total}` compatible with the
   established coverageText format. Memoization is the caller's job (40-03
   useMemo). Test: 8 dims, author excluded from group-by set, sentinel coverage
   math on a tiny fixture, month full-coverage.
2. **`activityGroupLayout.ts`** —
   - `categoryCentroids(counts: Uint32Array, spaceRadius)` — deterministic
     organic placement: phyllotaxis (sunflower) ordering by descending count
     with a seeded per-category jitter (mulberry-style hash of category id) so
     957 blobs read as an archipelago, never rows/grid. Footprint radius per
     category ~ sqrt(count) normalized to fill the space without heavy overlap.
   - `groupTargets(restPositions2, ids: Uint16Array subset values, centroids)`
     — per-node target: centroid + the node's rest offset direction/rank
     scaled into the footprint radius (preserves organic texture; NOT a pile).
     Single O(n) pass, Float32Array stride-2 out.
   - `groupStats(...)` — counts, restCentersX/Y (mean rest position per
     category), centersX/Y (the centroids), radii — aligned arrays sized
     cardinality, directly mountable on MapClusterLabels.
   - Test: determinism (same input → identical buffers), all K categories get
     distinct centroids at K=957, no NaN, targets land inside ~footprint,
     rest centroids equal fixture means.
3. **`activityColorBy.ts`** — `buildDimColors(ids, dim, theme?)`: module
   delegates to the existing buildModuleColorBuffer (7-color language
   unchanged); other dims ≤ ~24 categories → distinct palette (reuse the
   established chart/bucketed palette source, theme-resolved); high-cardinality
   → top-N (by count, N≈12) distinct + grey remainder; sentinel slot always
   muted grey. `buildDimLegend(...)` → LegendEntry[] with honest counts and an
   explicit "(+K more)" grey row for the remainder. Test: module passthrough
   byte-identical to moduleColors, top-N + grey split counts sum to total,
   legend honest.
