(`app/(dashboard)/users/access-analysis/`) and import the DuckDB client, the query module, the Mosaic

(`./duckdbClient`, `./analyticsQueries`, `./DistributionPanel`, `./HeatmapPanel`, `./HistogramPanel`,
`../useMergedAccUsers`). Vitest mocks by resolved module path, so keeping the specifiers identical is what
lets both tests' `vi.mock(...)` interceptions keep applying whether the code is imported by the shell or
the new hook — this is the whole reason the tests stay byte-identical.

into TerrainStage + TerrainControls to honor the ceiling), split the view into as many files as needed so
NO file exceeds ~400 lines — this is a justified deviation from the roadmap's literal "one thin view".

independently reviewable, with zero behavior change.

byte-identical and green.
