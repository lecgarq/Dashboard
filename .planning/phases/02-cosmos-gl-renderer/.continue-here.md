<completed_work>

**White canvas fix (committed earlier this session):**
- `graph.render()` called after `setPointPositions()` on first data load — Cosmos render loop was idling after empty init; explicit render() wakes it up

**UX improvement batch (uncommitted, applied this session):**

1. **Square border eliminated**: Cosmos `spaceSize` raised from 4096 → 65536 in `CosmosGraphRenderer.create()`

2. **Unlimited zoom (Canvas 2D)**: Zoom floor changed from `Math.max(10, ...)` → `Math.max(0.01, ...)` in AccUsersGraph.tsx wheel handler

3. **Organic placement — forceCenter removed**: The triple-centering (forceCenter + forceX + forceY) was collapsing nodes into a ring. forceCenter removed from d3-force simulation.

4. **Organic placement — repulsion scaled to D3-equivalent**: Old charge `-0.014` at default → new `-0.05` at default repulsion=1.0, which equals D3's default -30px at zoom 600. Formula: `-(0.015 + repulsion * 0.035)`

5. **Hidden hub node seed spread**: `seededPoint()` changed from tight ring (radius 0.06–0.28) to wide grid [0.08, 0.92] × [0.08, 0.92]

6. **Collision radius increased**: Visible nodes now `0.022 + repulsion * 0.006` (was `0.008 + spacing * 0.018`) — gives each node personal space like D3 collision example

7. **Link distance/strength now use physicsConfig**: `linkDistance()` and `linkStrength()` now read `physicsConfig.linkSpring` instead of the removed `controls.spacing`/`controls.clusterStrength`

8. **Unified physics sliders (both modes)**: Physics button and panel now visible in Canvas 2D AND GPU mode. `handlePhysicsChange` sends to both Cosmos (`setPhysicsConfig`) and d3-force worker (`{ type: "physics" }` message). Reset also hits both.

9. **Cosmos physics scaled in setPhysicsConfig**: repulsion × 1.5, linkSpring × 0.5, gravity × 0.3 — ensures same slider values give organic feel in both renderers

10. **New worker message type `physics`**: `PhysicsConfig` added to `accGraphOrganicLayout.ts`, worker handles `{ type: "physics"; physics: PhysicsConfig }` message, `init` message now includes `physics` field

11. **`cosmosPhysicsRef`**: Stable ref added alongside `cosmosPhysics` state — keeps physics value accessible in worker init message without stale closure
