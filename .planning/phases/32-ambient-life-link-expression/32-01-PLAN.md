## Tasks

1. **Pure ambient layer and FPS controller**
   - Add one allocation-free layer that hashes aligned node ids once, maps the six
     existing recency buckets to monotonic amplitude/speed constants, and writes
     anchor-relative x/y offsets into one reusable stride-3 buffer with z copied.
   - Support a precomputed freeze mask, focus-background softening, morph pause, a
     180ms zero-to-live resume envelope, Tier 1 recent-only 30Hz cadence, and Tier 2
     static output. No radius/color/glow mutation and no random walk.
   - Add the three-tier sampler with two low 3-second windows for each downgrade,
     55fps/10-second hysteretic one-tier recovery, and sampler reset without tier
     flapping. Unit-pin determinism, recency order, no drift, freeze, pause/resume,
     buffer identity, tier cadence, thresholds, and recovery.

2. **Compose after authoritative anchors on the frozen rAF path**
   - Build the layer once in `ShellBody` from `feature.nodeId` and
     `activityRecencyBucket`; build one freeze mask only when hover/focus membership
     changes and pass focus state without per-frame React updates.
   - In `GraphCanvas`, apply ambient after the catalog transition snapshot. Treat an
     active slider or unsettled catalog transition as paused, route reduced motion to
     exact anchors, and reset sampling on media-query or visibility changes.
   - Extend the existing renderer test to prove the ambient frame feeds the current
     override/push path and preserve the PERF-02 source/invariant assertions: no new
     simulation `start`, `resumeSimulation`, cluster mutation, renderer, or canvas.

3. **Production evidence seam and browser gate**
   - Extend only the flag-gated `__ACC_GRAPH_TEST__` bridge with ambient stats,
     similarity-edge count, and a synchronous exercise of the real controller's
     locked low/high window sequence; do not add a second graph interaction path.
   - Add a Phase-32 Playwright gate for both aliases, full >22k snapshot readiness,
     3-second warmup + 10 continuous seconds of actual rAF sampling, recorded tier /
     animated count / edge count, observed Tier 0 -> Tier 1 and recovery, focus
     continuity, and reduced-motion static output.
   - A full-mode claim is allowed only when the actual 10-second sample is >=50fps
     and stays Tier 0. Otherwise record the measured failure and the controller's
     observed degraded tier; never relabel degraded output as full ambient.
