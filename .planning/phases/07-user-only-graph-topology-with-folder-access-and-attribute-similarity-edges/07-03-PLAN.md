<objective>
Build the pure similarity-computation module that emits up to 5 parallel user↔user edges per pair (one per dimension: folder-access, roles, projects, company, admin-tier).

Purpose: This is the backbone of the "user-only" view mode and the multi-kind enrichment. Pure function so it's memoizable in the renderer adapter without React entanglement. The folder-access dimension is computed transitively (user → roles → folders) per RESEARCH Pitfall 2 + Open Question 1 — `AccFolderPermission` carries only role permissions, not user permissions. Caller is responsible for the role→folder resolution; this module accepts pre-resolved `folderIds: string[]` per user.
Output: 1 source file + 1 Vitest file.
</objective>
