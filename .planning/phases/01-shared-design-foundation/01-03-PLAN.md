Create `components/ui/PremiumSurface.tsx` per the RESEARCH.md §2 / ARCHITECTURE.md §2b contract. Props: `{ variant?: "base" | "float" | "glass" | "inset"; glow?: boolean; className?: string; children: React.ReactNode } & React.ComponentProps<"div">`. Default `variant` to `"base"`.

Map each variant to token-driven classes (FND-01 tokens from plan 01 — no hardcoded hex in this TSX):

- `inset` → an inset/recessed shadow + `bg-muted/30`.
- `glow` → conditionally append `shadow-[var(--glow-primary)]` (or a `ring`-based indigo accent reading `--glow-primary`). Compose with `cn(...)` so it layers onto the variant shadow.

Always include `"relative"` in the root class list.
