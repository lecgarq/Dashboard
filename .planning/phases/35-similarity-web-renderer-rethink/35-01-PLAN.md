## Tasks

1. Reconfirm the current Canvas2D control on the established isolated `:3100`
   production harness: full live graph, same camera, >=3s warm-up, >=10s rAF sample.
   Record node count, mapped edge count, FPS, tier, and existing profile counters.
2. Prototype **Cosmos-native curved links** using installed 3.3.0 only: full indexed
   link buffer, per-link RGBA/width, curve controls, global morph opacity, and complete
   selected/hovered focus layers. Run the identical sample and capture a rest/focus/morph
   screenshot or equivalent browser evidence. `VERIFY:` tune the GPU curve against the
   current 0.14 quadratic bow rather than assuming equivalence.
3. Prototype **OffscreenCanvas worker rasterization** over the same full mapped edge set.
   Keep projection/state transport minimal and record both FPS and main-thread cost; this
   candidate may be discarded immediately after measurement.
4. Prototype **deterministic zoom-decimated Canvas** using a stable ambient subset while
   keeping selected/hovered links complete. Measure the same view at the chosen zoomed-out
   threshold and confirm the settled close view restores all ambient links without reshuffle.
5. Compare all candidates against the historical ~40ms/frame / 41.33fps Phase-33 result.
   Choose the smallest candidate or combination that materially removes the main-thread
   raster ceiling and satisfies the locked visual decisions. Prefer native alone when it
   wins; decimation is fallback-only.
6. Remove all prototype-only edits with explicit reverse patches; verify the only plan
   artifact left is `35-BASELINE.md`. Commit it explicitly:
   `docs(35): record renderer candidate measurements`.
