<tasks>
1. **Install + verify pacmap (VERIFY-A).** `pip install pacmap` (expect 0.9.1 +
   faiss-cpu 1.14.3, dry-run-verified 2026-07-16). Then inspect the installed API:
   `python -c "import pacmap, inspect; print(pacmap.__version__); print(inspect.signature(pacmap.PaCMAP.__init__))"`.
   Record: determinism guarantee of `random_state`, accepted `distance` strings,
   `apply_pca` default/behavior. If "angular" is unavailable, fall back to the closest
   cosine-family option the package actually supports and record the deviation.

2. **Loader + numeric normalization.** Extend `_load_jsonl` to also return a numerics
   list (tolerate missing `numerics` key → all-null row, backward compatible). New pure
   function `normalize_numerics(rows) -> (matrix, col_names)` implementing the CONTEXT
   defaults:
   - `log1p` then max-scale (max→1.0, guard max=0) for `accessibleDataBytes`,
     `activityTotal`, `folderBreadth`, `membershipAgeDays`;
   - `/5.0` for `permissionStrength`, `riskScore` (bounded ordinals);
   - `membershipAgeDays` and `permissionStrength` get a paired `<name>_missing` 0/1
     column; their value column uses 0 when missing (indicator disambiguates);
   - `folderBreadth`/`accessibleDataBytes`/`activityTotal`/`riskScore` nulls → 0
     (missing ≈ none; `cov:` token carries crawl-coverage truth) — documented in-code.

3. **Hybrid assembly.** Pure function `build_hybrid_matrix(tfidf, numeric)`: scale the
   numeric block by `mean_row_norm(tfidf_block) / mean_row_norm(numeric_block)` (guard
   zero), then `scipy.sparse.hstack`. Unit-pin: after scaling, per-block mean row-norms
   are equal within tolerance.

4. **PaCMAP projection.** Replace `project_tsne` with `project_pacmap(matrix)`:
   - `n < 10` → keep the existing TruncatedSVD fallback verbatim;
   - else TruncatedSVD-reduce the sparse hybrid to ~100 comps (skip when already ≤100
     cols), then `PaCMAP(n_components=2, n_neighbors=10, distance=<verified cosine-family>,
     random_state=RANDOM_STATE, ...)` per VERIFY-A. Tight-islands target: keep
     `n_neighbors` near default 10; MN/FP ratios only if defaults fail the look —
     record any non-default.

5. **Full-set projection + residual jitter.** `main()` projects ALL rows (no
   `matrix[first]`). `dedupe_docs` stays as the measurement tool only. New pure function
   `residual_jitter(coords, dup_key_rows)`: gaussian jitter (existing JITTER_FRAC
   machinery) applied ONLY to rows whose (tokens + raw numerics) tuple is still
   byte-identical to an earlier row. KMeans-12 now runs on the full-set 2D coords.

6. **Quality gate (EMB-04/05).** In `main()`:
   - duplicate rate OLD definition (tokens-only key) and NEW (tokens+numerics key),
     both printed;
   - fetch old coords `SELECT "nodeId","x","y" FROM "AccInstanceEmbedding"` (psycopg,
     read-only) joined by nodeId; compute `sklearn.manifold.trustworthiness(hybrid, coords, n_neighbors=10)`
     for old and new on the SAME row subset (nodes present in both) and, per VERIFY-B,
     the same seeded subsample if full-n is infeasible;
   - print both numbers; if `new < old` → print FAIL and `sys.exit(1)` BEFORE upsert
     (gate = ship-blocker, decision §4). No old coords in DB (first run edge) → skip the
     comparison with an explicit printed note, gate passes on duplicate-rate-drop alone.
   - print total pipeline runtime.

   `'features → PaCMAP'`. ⚠️ The file carries 2 lines of pre-existing WIP (deleted

   - residual_jitter: identical rows move, distinct rows untouched;
