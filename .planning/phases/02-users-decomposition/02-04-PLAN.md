<objective>
Move all filter / search / sort / viewMode / selection UI state out of the shell's
useState calls into a dedicated Zustand store, replacing the full `selectedPerson`
object with a stable `selectedEmail` string. The shell keeps refs, tRPC utils, and
hover-prefetch callbacks (those cannot live in a store).

Purpose: USR-01 — the Zustand store is the named decomposition target and the seam
Phase 4's DataTable will consume. The selectedEmail-not-object choice (RESEARCH
Pattern 1 + Open Q2) keeps the store serializable and the setter stable so closing
the modal never resets scroll.
Output: useUsersDirectoryStore.ts + its unit test; shell wired to the store.
</objective>
