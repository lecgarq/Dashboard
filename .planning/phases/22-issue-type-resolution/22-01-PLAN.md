Append to `prisma/schema.prisma` (additive — touch nothing else):

```prisma
model AccIssueType {
  id           String   @id // APS issue-type or issue-subtype GUID
  name         String
  kind         String   // "type" | "subtype"
  parentTypeId String?  // set only when kind = "subtype"; the parent type's GUID
  updatedAt    DateTime @updatedAt // freshness record — no separate run-audit table (locked decision)

  @@index([kind])
  @@index([parentTypeId])
}
```

   indexes — nothing touching AccInstanceEmbedding / AccActivityAccds / any vector column.

   then `npx prisma generate`.
