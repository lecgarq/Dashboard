Required test blocks:

1. **MATH-04 zero state**: all sliders = 0 → position = (0,0,0). Use `expect(Array.from(pos)).toEqual([0, 0, 0])` for bit-exact match.

2. **MATH-03 single slider, single dim**: activity=1, all others=0 with node.activity=1 → x ≈ R (300), y ≈ 0, z = 0. Use `toBeCloseTo` with precision 4 for x/y, strict equality for z.

3. **MATH-03 two-slider additive blend**: activity=1 and recency=1 with node.activity=1, node.recency=1 → expectedX = (R*1*cos(0) + R*1*cos(π/2)) / 2 = R/2; expectedY = R/2. Assert with toBeCloseTo precision 4.

4. **MATH-02 dimension axis distribution**: Run with 4 dims, single-slider-on-each (one at a time), node values all 1. Confirm output positions land at (R,0), (0,R), (-R,0), (0,-R) approximately (precision 3 — sin/cos floating drift).

6. **MATH-04 monotonicity property (fast-check)** — encode the observable axis per RESEARCH Open Question #2:
   - Hold slider `recency=1` fixed
   - Sweep slider `activity` from sLo to sHi where sLo < sHi (both in [0,1])
   - Node features: activity=1, recency=1 (both endpoints fully expressed)
   - As `activity` slider grows, the position trajectory moves from "pure recency endpoint" (0, R) toward "midpoint of activity & recency" (R/2, R/2). Distance from the "pure recency endpoint" (0, R) must be **non-decreasing** as `activity` slider grows.
   - Formally:
```typescript
fc.assert(
  fc.property(
    fc.double({ min: 0, max: 1, noNaN: true }),
    fc.double({ min: 0, max: 1, noNaN: true }),
    (a, b) => {
      const [sLo, sHi] = a <= b ? [a, b] : [b, a];
      const n = node({ activity: 1, recency: 1, isAdmin: 0, isExternal: 0 });
      const pLo = computeTargetPositions([n], dims, { activity: sLo, recency: 1, isAdmin: 0, isExternal: 0 });
      const pHi = computeTargetPositions([n], dims, { activity: sHi, recency: 1, isAdmin: 0, isExternal: 0 });
      // Distance from "pure recency endpoint" (0, R) where R=300:
      const dLo = Math.hypot(pLo[0] - 0, pLo[1] - 300);
      const dHi = Math.hypot(pHi[0] - 0, pHi[1] - 300);
      return dHi + 1e-6 >= dLo; // non-decreasing
    },
  ),
  { numRuns: 100 },
);
```

```typescript
describe("mathLayer purity (MATH-05)", () => {
  it("imports no React, DOM, engine, or persistence modules — has zero imports total", () => {
    const src = readFileSync(resolve(__dirname, "./mathLayer.ts"), "utf8");
    const specifiers = [
      ...src.matchAll(/import\s+(?:[^"';]+from\s+)?["']([^"']+)["']/g),
      ...src.matchAll(/import\(\s*["']([^"']+)["']\s*\)/g),
    ].map(m => m[1]);
    expect(specifiers).toEqual([]);
  });

  it("contains no forbidden module identifiers in source text", () => {
    const src = readFileSync(resolve(__dirname, "./mathLayer.ts"), "utf8");
    // Defensive: even type-only references via `///<reference>` or jsdoc @import should not appear
    const forbidden = ["react", "next/", "three", "d3-force", "react-force-graph", "duckdb-wasm", "apache-arrow"];
    for (const term of forbidden) {
      expect(src.toLowerCase()).not.toContain(term.toLowerCase());
    }
  });

  it("contains no Math.random or Date.now calls (determinism)", () => {
    const src = readFileSync(resolve(__dirname, "./mathLayer.ts"), "utf8");
    expect(src).not.toMatch(/Math\.random\b/);
    expect(src).not.toMatch(/Date\.now\b/);
    expect(src).not.toMatch(/new Date\b/);
  });
});
```
