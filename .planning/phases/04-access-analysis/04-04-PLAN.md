    Create new file `server/routers/workspace.ts` (NOT under `app/` — server tRPC routers live in `server/routers/`). Mirror the OAuth client construction from `server/routers/gmail.ts` exactly (refresh_token lookup, oauth2 setCredentials).

    Inside the protectedProcedure query:
    1. Look up `ctx.db.account.findFirst({ where: { userId: ctx.session.user.id, provider: "google" }, select: { refresh_token: true, access_token: true } })`. If no `refresh_token`, throw `new TRPCError({ code: "PRECONDITION_FAILED", message: "workspace_access_required" })` — UI can render a friendly inline message.

    2. Build google.auth.OAuth2 client + setCredentials (per gmail.ts pattern).

    3. Call `google.people({ version: "v1", auth: oauth2 }).people.listDirectoryPeople({...})`. Use TypeScript inference to determine the correct `sources` enum value (Open Q2):
       - Try `["DIRECTORY_SOURCE_TYPE_DOMAIN_PROFILE"]` first (matches RESEARCH.md research code example).
       - If TypeScript rejects the literal at compile, inspect `node_modules/googleapis/build/src/apis/people/v1.d.ts` for the correct enum and update.
       - Document the verified value in a JSDoc comment.

    4. Pagination loop: `while (pageToken && pageCount < 25)` — accumulate emails into a `Set<string>` (lowercase). 25 pages × 1000 page size = 25,000 user safety cap (Pitfall 3).

    5. On API call failure:
       - 403 / scope missing → throw `TRPCError({ code: "FORBIDDEN", message: "workspace_scope_missing" })`.
       - Other errors → log + throw INTERNAL_SERVER_ERROR.

    6. Empty `emails` set is a valid response (Open Q5: user not in a Workspace tenant) — return `{ emails: [] }` with NO error.

    7. Server-side cache: use a module-level `Map<userId, { value: string[]; expires: number }>` for a simple 1-hour TTL. (Do NOT introduce Redis here — the project has @upstash/redis but for simplicity, in-memory cache scoped to the server process is sufficient for v1.0; document this limitation.) Cache key = userId. On cache hit within TTL, return cached emails immediately.

    Use `import { router, protectedProcedure } from "../trpc"` — match the existing relative-import style of other server routers.

    Avoid: `directory.users.list` (Admin SDK — wrong scope; Pitfall on RESEARCH.md "Anti-Patterns"); pulling new env vars (reuse the existing GOOGLE_CLIENT_ID/SECRET); adding a new Prisma migration.
