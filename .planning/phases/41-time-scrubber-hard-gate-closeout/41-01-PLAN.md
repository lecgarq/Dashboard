   category palette stable. Expose live tier/fps from `activityMotion` without

   contract. Extend the bridge with temporal, finite-position, renderer, and
   ambient-performance evidence.
4. Run the visual design gate against the changed shell (`impeccable detect`) and
   fix only findings introduced by this scrubber.
