   `NEXT_PUBLIC_ACC_GRAPH_TEST=1`, start it on `:3100`, and run the Phase-34 re-baselined

   framebuffer results. Stop and investigate the first honest failure; do not cherry-pick.
6. Write `36-01-SUMMARY.md` and `36-VERIFICATION.md` with exact evidence. If all criteria
   pass, deploy through the repository autoDeploy sequence, append BUILD_ID/health/route
   probes, check REND-02 and Phase 36 in REQUIREMENTS/ROADMAP, and route STATE to
   `$lecg-close-milestone`.
