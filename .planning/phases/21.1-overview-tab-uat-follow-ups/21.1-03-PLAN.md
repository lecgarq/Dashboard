Create `app/(dashboard)/access-analysis/projectActivityCounts.ts` — pure, no React/DOM/IO:

```typescript
import type { ModuleActivityRow } from "@/lib/acc/moduleCountsTypes";
export const DEFAULT_TOP_N = 10;
export interface ProjectActivitySlice {
  projectId: string;    // "" for the Other bucket
  name: string;         // projectName, or "Other (N projects)"
  value: number;        // total activity volume
}
export interface ProjectActivitySummary {
  slices: ProjectActivitySlice[];              // top-N desc + trailing Other (when rest exists)
  total: number;                               // included volume (Account-level excluded)
  accountLevelCount: number;                   // excluded synthetic-bucket volume, for the caption
  otherProjectCount: number;                   // projects folded into Other (0 if none)
  rowsByProject: Map<string, ModuleActivityRow[]>; // drill payload for KEPT slices only
}
export function summarizeProjectActivity(
  rows: ReadonlyArray<ModuleActivityRow>,
  topN: number = DEFAULT_TOP_N,
): ProjectActivitySummary
```

Implementation (mirror `summarizePermissionLevel`'s loop structure):
1. Partition out `projectId === ""` rows first, summing their volume into `accountLevelCount`
   (comment: exact sentinel from `moduleActivityView.ts`'s ACCOUNT_LEVEL logic — CONTEXT.md
   locks the exclusion + caption note).
2. Map-accumulate remaining rows by projectId (`value += count`; keep `projectName` from the
   first row; collect the raw rows per project for `rowsByProject`).
3. Sort desc by value, tiebreak `name.localeCompare`; `slice(0, Math.max(0, topN))` kept;
   rest collapses to one `{ projectId: "", name: "Other (N projects)" }` slice (singular
   "project" when N === 1, matching permissionLevelCounts' noun convention). No drill entry
   and no rowsByProject entry for Other.
4. `total` = kept + Other volume (i.e. all non-Account-level volume) so donut percentages
   sum to 100%.

Test (`__tests__/projectActivityCounts.test.ts`, mk-helper style from moduleCounts.test.ts):
- empty rows → empty slices, total 0, accountLevelCount 0;
- Account-level exclusion: rows with projectId "" contribute only to accountLevelCount, never
  a slice, and total excludes them;
- top-N + Other: 12 projects with distinct volumes → 10 kept desc + "Other (2 projects)"
  whose value = sum of the two smallest; otherProjectCount === 2; singular noun for one;
- `topN = rows-projects-count` (expand-in-place semantics) → no Other bucket;
- rowsByProject: kept project's rows preserved verbatim (usable by summarizeModules), no
  entry for Other or Account-level;
- slices sum: sum(slices.value) === total.
