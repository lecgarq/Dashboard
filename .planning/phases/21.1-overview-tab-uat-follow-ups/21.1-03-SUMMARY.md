## What Was Built

### Task 1: `summarizeProjectActivity` pure transform

`app/(dashboard)/access-analysis/projectActivityCounts.ts` aggregates the
`ModuleActivityRow[]` rows the Overview already loads (`loadModuleActivity()`
via the `moduleRows` prop — **no new loader, no new fetch**) per `projectId`:

- Rows with `projectId === ""` (the synthetic Account-level bucket, the exact
  sentinel `moduleActivityView.ts`'s `ACCOUNT_LEVEL` logic produces) are
  partitioned out first and summed into `accountLevelCount` — they never
  become a slice or a `rowsByProject` entry.
- Remaining rows are Map-accumulated by `projectId`, sorted desc (tiebreak
  `projectName.localeCompare`), `slice(0, topN)` kept, the rest collapsed
  into one trailing `"Other (N projects)"` slice (singular noun for N === 1).
- `total` sums kept + Other volume, so donut percentages add to 100%
  (verified: `sum(slices.value) === total`).
- `rowsByProject` carries each **kept** project's raw rows verbatim (no entry
  for Other or Account-level) — the exact drill payload plan 21.1-04's donut
  feeds into `summarizeModules`.

8 new Vitest cases cover: empty input, Account-level exclusion, aggregation +
sort, 12-project top-10+Other bucketing with the correct Other volume,
singular-noun Other, `topN === distinct-project-count` (no Other bucket, i.e.
expand-in-place semantics), `rowsByProject` fidelity, and the sum invariant.

### Task 2: `ProjectActivityDonut` component

`app/(dashboard)/access-analysis/components/ProjectActivityDonut.tsx` renders
an ECharts donut (mirrors `ModulesPieChart`'s option shape: donut ring, center
labels, item tooltip, `useTheme()` dark-default colors) with a ranked legend
below it (mirrors `ModulesPieChart`/`RolesPieChart`'s legend-button pattern):

- **Local drill only** (no `onSliceClick`/`activeSlice`/shared filter-store
  wiring, verified by a source-grep test) — clicking a kept project slice
  toggles `useState<string | null>` and computes
  `summarizeModules(rowsByProject.get(id))` in a `useMemo`, rendering the
  module breakdown **after** the legend (the 20.1-07 scroll-jump lesson:
  drill content never inserts above the row the user just clicked).
- The Other slice has no `rowsByProject` entry, so `toggleDrill` is a
  guaranteed no-op for it — clicking it does nothing (verified by test).
- **Categorical color palette** (name-keyed hue rotation, mirroring
  `RolesPieChart`'s convention since the identity axis here is *project*, not
  a fixed taxonomy) with the Other slice always getting the muted zinc
  `#71717a` rollup color (`ModulesPieChart`'s `UNMAPPED_COLOR` role).
- **Caption** (always live, never hardcoded): "Account-level admin activity
  ({accountLevelCount} actions) is excluded." when `accountLevelCount > 0`,
  plus "Top {N} of {N+otherProjectCount} projects" when the Other bucket
  exists. Both lines are individually conditional and omitted when they
  don't apply (verified by test).
- **Empty state**: `slices.length === 0` renders the same visual-weight
  zinc-muted empty panel convention as `ModulesPieChart`.

7 new Vitest cases cover: empty state, slice rendering (kept projects + Other,
excluding the folded-in project), drill open/close on a project slice, no-op
on the Other slice, live caption figures present, captions omitted when
neither condition applies, and the cross-filter-bus absence grep.
