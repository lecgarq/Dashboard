## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Block-comment `*/` sequence broke the loader's doc comment**
- **Found during:** Task 1 (initial Vitest run)
- **Issue:** The first draft of `provisionedModulesView.ts`'s doc comment contained the literal text "AccActivity*/AccFolder*-scale", where `*/` inside a `/* ... */` JSDoc block terminated the comment early, producing a parse error (`Expected a semicolon...`).
- **Fix:** Reworded to "AccActivity- and AccFolder-scale tables" (no `*/` sequence).
- **Files modified:** `lib/server/provisionedModulesView.ts`
- **Verification:** `npx vitest run lib/server/provisionedModulesView.test.ts` passed after the fix.
- **Committed in:** `7f8e9f83` (Task 1 commit)

**2. [Rule 1 - Bug] Doc comment literally contained the banned cross-filter-bus token, failing its own grep test**
- **Found during:** Task 3 (`ProvisionedModulesChart.test.tsx`'s no-cross-filter-bus source-text assertion)
- **Issue:** The component's JSDoc explained what it does NOT do using the literal strings `` `onSliceClick`/`activeSlice`/`sliceFilters` ``, which trivially failed the test's `expect(source).not.toContain("onSliceClick")` assertion (the test greps the raw file text, not just executable code).
- **Fix:** Reworded the doc comment to describe the absence of cross-filter-bus wiring without using the literal banned token strings.
- **Files modified:** `app/(dashboard)/access-analysis/components/ProvisionedModulesChart.tsx`
- **Verification:** `npx vitest run "app/(dashboard)/access-analysis/__tests__/ProvisionedModulesChart.test.tsx"` passed after the fix.
- **Committed in:** `a083219b` (Task 3 commit)

**3. [Rule 1 - Bug] `label.formatter` type mismatch caught by `tsc --noEmit`**
- **Found during:** Task 3 (post-implementation `npx tsc --noEmit` gate)
- **Issue:** The bar-value label formatter was typed as `(p: { value?: number }) => string`, which is not assignable to ECharts' `LabelFormatterCallback<CallbackDataParams>` (whose `value` type is a much wider union including `null`).
- **Fix:** Changed the formatter parameter to `unknown`, then narrowed with a runtime `typeof value === "number"` check before calling `.toLocaleString()`.
- **Files modified:** `app/(dashboard)/access-analysis/components/ProvisionedModulesChart.tsx`
- **Verification:** `npx tsc --noEmit` -> 0 errors after the fix; re-ran the component's Vitest suite to confirm no behavior change.
- **Committed in:** `a083219b` (Task 3 commit)
