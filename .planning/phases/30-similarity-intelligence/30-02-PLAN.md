## Tasks

1. **`lib/acc/embedding/neighborPayload.ts`** (new, pure — no DB/React imports,
   matches the lib/acc/embedding module style):
   ```ts
   export interface NeighborMatch { nodeId: string; score: number; why: string[] }
   export interface NeighborTwins { count: number; ids: string[] }
   export interface NeighborsPayload { matches: NeighborMatch[]; twins: NeighborTwins }
   export function normalizeNeighborsPayload(raw: unknown): NeighborsPayload
   ```
   - v2 object (`v === 2` or `matches` array present): coerce matches (drop
     entries without string nodeId / finite score; default `why: []`), coerce
     twins (default `{count: 0, ids: []}`).
   - Old bare array `[{nodeId, score}]`: map to matches with `why: []`,
     `twins: {count: 0, ids: []}`.
   - null / non-array garbage / malformed entries: empty payload — never throw.

2. **`server/routers/acc-dc-graph.ts`**
   - `instanceNeighbors`: return `normalizeNeighborsPayload(row?.neighbors)`.
   - `similarityEdges`: per row, `neighbors: normalizeNeighborsPayload(r.neighbors).matches`
     (RawNeighbor shape is `{nodeId, score}` — extra `why` field is structurally
     compatible; keep the mapping explicit `{nodeId, score}` to keep the wire
     model clean). `dedupeAndSelectClusterAware(nodes, clusterById, limit)` call
     unchanged (default `interReserveFrac = 0.4` stays until 30-04 evidence).
   - Update the cluster-aware comment: twin edges are now collapsed upstream;
     keep the bridge-reserve rationale but note the re-tune evidence lives in
     the Phase 30 verification.

3. **Tests**
