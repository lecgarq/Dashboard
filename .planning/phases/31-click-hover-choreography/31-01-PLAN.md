## Tasks

1. **Native camera session on the frozen 2D handle**
   - Add the smallest typed view snapshot (`center`, `zoom`) and handle methods:
     capture from the canvas midpoint, focus through
     `zoomToPointByIndex(index, duration, 2.25, false, false)`, and restore through
     `setZoomTransformByPointPositions([center], duration, zoom, 0, false)`.
   - In `GraphInteractions`, snapshot only on the first null→node transition,
     focus subsequent node changes without replacing the snapshot, and restore on
     any node→null transition. Existing background click, Esc, and rail Close all
     continue to clear through `setIsolated(null)`.
   - Read `prefers-reduced-motion` at action time; use duration 0 when active.
   - Extend `GraphCanvas.test.ts` and `GraphInteractions.test.tsx` to pin call
     arguments, one-snapshot semantics, exact restore, and zero simulation starts.

2. **Match-only mask and focus-edge model**
   - Remove the same-user isolate branch and now-unused parsing from
     `usePredicateEngine`; leave filter/search/lasso behavior untouched.
   - Add a pure `resolveFocusEdges` helper over the already-indexed global web:
     selected edges follow the Phase-30 matches and synthesize any missing direct
     pair from the real selected/match indices + stored score; hover edges are only
     incident edges already present in the global web (no hover fetch).
   - Extend the overlay in place: ambient web first, dimmed to 15% while selected;
     selected curves second at fixed emphasis width; hovered curves last. Reuse the
     current affine projection and Canvas2D renderer—no second canvas/renderer.
   - Unit-pin same-user exclusion, fallback edge presence, and hover incident-edge
     resolution.

3. **Immediate hover + delayed truthful tooltip**
   - Keep the renderer hover ring immediate and lift the hovered index to the shell
     solely for overlay emphasis; do not alter isolate/mask/query state.
   - Split immediate hover state from tooltip disclosure with one cancellable 80ms
     timeout. Compute `canvasOriginXY` from the actual GraphInteractions wrapper.
   - Replace the identity-heavy tooltip body with compact identity/project context
     plus permission tier, `activityRecencyBucket`, and folder breadth.
     `permissionCoverage:"unknown"` renders tier/breadth unavailable; partial
     breadth is explicitly labeled partial.
   - Add focused tooltip and timer-cancellation tests.
