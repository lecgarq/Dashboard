# Plan 34-01: GUARD-01 — close the powershell-wrap bypass in guard-bash

## Objective

`powershell -Command "npm run build"` currently becomes `powershell -Command ""`
after the quote-strip at `.claude/hooks/guard-bash.cjs:16`, so the build regex
(line 43) never sees the payload — the exact Phase-33 incident that overwrote the
live `.next`. Close it per CONTEXT Decision 2 (scope: `powershell`+`pwsh`,
`-Command` forms only; `-File`/`-EncodedCommand` recorded OUT) and Decision 4
(commit the uncommitted isolatedDist WIP first, as its own chore commit).

2. **Wrapped-payload inspection.** In `guard-bash.cjs`, BEFORE the quote-strip:
   detect a `powershell`/`pwsh` `-Command` invocation and extract its quoted
   payload (first quoted argument after `-Command`, single- or double-quoted; also

   documenting the trap: bash expands `$env:` inside double quotes to empty

   from bash is the established form.

3. **Testability seam.** The :3000 probe port is hardcoded; unit tests cannot bind
   :3000 while the workshop app serves. Add
   `const PORT = Number(process.env.GUARD_BASH_PORT || 3000);` and use it in the
   socket probe — smallest injectable seam, default behavior identical.

4. **Hook unit test** at `tests/hooks/guard-bash.test.ts` (npm test excludes only
   `tests/e2e/`; VERIFY vitest picks the file up — if not, move it under
   `scripts/` and note in summary). Spawn `node .claude/hooks/guard-bash.cjs` with
   a JSON stdin payload (`{tool_input:{command}}`), `GUARD_BASH_PORT` pointed at
   an ephemeral `net.createServer` listener (deny cases) or a closed port (allow
   cases). Assert stdout contains/lacks `"permissionDecision":"deny"`. Cases:
   - `powershell -Command "npm run build"` + listener → deny
   - `pwsh -Command 'npm run build'` + listener → deny
   - `pwsh -Command 'NEXT_DIST_DIR=.next-e2e npm run build'` (isolatedDist inside
     wrapper; PowerShell equivalent `$env:NEXT_DIST_DIR='.next-e2e'; npm run build`

   - bare `npm run build` + listener → deny (regression)
   - `git commit -m "powershell -Command npm run build"` → allow (quote-strip
     still protects quoted text on the non-wrapped path)
   - `git add -A` → deny (bulk-stage guard untouched)
