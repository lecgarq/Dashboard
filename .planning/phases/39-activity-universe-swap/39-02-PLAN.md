# 39-02 — Event interaction: hover, click story, lasso (ACT-04)

## Objective

Every rendered activity node tells its story: instant hover tooltip from
resident data, click → on-demand event detail + author profile, lasso with
honest counts, coverage label on the surface.

## Context (@ paths)

- @.planning/phases/39-activity-universe-swap/39-CONTEXT.md
- @app/(dashboard)/users/access-analysis/activity/ActivityUniverseShell.tsx (39-01)
- @app/(dashboard)/users/UserProfilePanel.tsx — props: {user: null, email,
  variant:"rail", onClose} verified sufficient (fetches via accDcGraph.bulkUser)
- @app/(dashboard)/users/access-analysis/NodeTooltip.tsx — established tooltip style
- @app/(dashboard)/users/access-analysis/LassoOverlay.tsx — 2D lasso overlay;
  reuse if its props decouple from GraphInteractions, else minimal adaptation
- @server/routers/acc-dc-graph.ts — router registration pattern (adminProcedure)
- @prisma/schema.prisma — AccActivityAccds (PK accdsActivityId; objectName,
  folderName, userName, createdAt), AccActivity (PK id; rawAction, details),
  AccActivityEmbedding (PK id = "a:"+accdsActivityId | "d:"+AccActivity.id)
- @DESIGN.md — rail/tooltip chrome must match the dense operational style

Key facts: payload has NO per-row id string — index→id resolution required.
Rows are streamed ORDER BY id at build time, so row index = rank in id order
AT BUILD TIME. Table drift after build would shift ranks → anchors must come
from the artifact build, not runtime (consistency guard below).

## Tasks

1. **Builder: emit `idAnchors`** — in
   `scripts/build-activity-universe-payload.ts`, while streaming, capture every
   10,000th row's id (index 0, 10000, 20000, …) into `meta.idAnchors: string[]`
   (~491 entries). Additive meta field; bump nothing (version stays 1,
   `idAnchors?` optional in the type). Add `anchorFor(index)` pure helper +
   vitest in `lib/server/activityUniversePayload.ts`. **Re-run the builder**
   (`npx tsx scripts/build-activity-universe-payload.ts`, ~1 min) and verify
   meta now has idAnchors with count matching ceil(4,904,886/10,000).
2. **`server/routers/activity-universe.ts`** (adminProcedure):
   - `projectNames` — `accProject.findMany({select:{id,name}})` → Record<guid,name>
     (957 rows; client staleTime Infinity).
   - `eventDetail({index})` — read meta (readActivityUniverseMeta); resolve id:
     `SELECT id FROM "AccActivityEmbedding" WHERE id >= $anchor ORDER BY id
     OFFSET $rem LIMIT 1` (rem = index % 10,000; PK index-only scan). Then by
     prefix: "a:" → AccActivityAccds findUnique (verb, objectType, objectName,
     folderName, projectId, userName, userEmail, exact createdAt); "d:" →
     AccActivity findUnique (rawAction, service, projectId, userEmail,
     createdAt). Join project name. Consistency guard: compare the row's
     projectId GUID against the client-supplied expected GUID (input field);
     mismatch → `{stale: true}` so the client shows "details unavailable (data
     refreshed since load)". Never LOWER() on activity tables.
   - Register in the root router. Focused vitest for the pure pieces (anchor
     math, id-prefix branch, stale guard) with mocked db.
3. **Hover tooltip** — `activityEventLabels.ts` pure resolver (index + columns +
   dicts + projectNames → {verb, module, project, month "MMM YYYY", author,
   role, company}) + test; `ActivityTooltip.tsx` renders it in the established
   NodeTooltip visual style. Wire via GraphCanvas2D `setEventHandlers`
   onPointHover (rendered→full index mapping from 39-01).
4. **Click → `ActivityDetailRail.tsx`** — right rail: event story header
   (verb + object/folder names + exact timestamp from `eventDetail`, loading +
   "details unavailable" states), then author section: authorId 0 → explicit
   "Unknown author" card (count context from coverage meta); else
   `UserProfilePanel` with `{user: null, email, variant: "rail", onClose}`.
   Esc/close returns to base state.
5. **Lasso + selection honesty** — reuse/adapt the 2D lasso path against the
   handle's `findPointsInPolygon` (operates on rendered subset natively).
   Selected-count label: "N of rendered ~500k selected". Keep selection state
   tiny (indices array); no instance SelectionPanel machinery.
6. **Coverage label** — muted caption on the graph surface from meta coverage:
   "author resolution 94.41% · unknown authors 5.59%" (exact figures from meta,
   not hardcoded — meta is the source).
7. **Design gate** — visual surface changed: run `impeccable detect`-tier
   self-check against DESIGN.md (dense, zinc, muted captions, ≤200ms motion,
   reduced-motion static) before declaring done.
