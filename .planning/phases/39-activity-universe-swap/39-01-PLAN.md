# 39-01 — Activity universe render swap (ACT-01)

## Objective

Both graph routes render one node per activity event at rung L2: full 4.9M set
resident client-side (binary payload), far zoom renders a deterministic uniform
sample ≤ ~500k via the `setPointSet` seam, colored by module/serviceGroup,
static/frozen. Instance-graph prefetch stops shipping bytes on these routes.

## Tasks

1. **Move the columnar codec to `lib/acc/columnarPayload.ts`** (with its test).
   Update all importers: `ScaleSpikeClient.tsx`, `app/api/scale-spike/payload/route.ts`,
   `scripts/build-activity-universe-payload.ts`, `tests/e2e/activity-payload.spec.ts`.
   Delete the old `scale-spike/columnar.ts` + test. Gate: `npx tsc --noEmit`,
   moved vitest green, repo-map check (shared-module move).
2. **Pure transforms + tests** in `app/(dashboard)/users/access-analysis/activity/`:
   - `moduleColors.ts` — moduleId → RGBA Float32Array(n*4) from a theme-resolved
     palette keyed by the module dict labels (match /access-analysis module color
     language; resolve CSS vars at runtime like existing chart color helpers).
     Legend model derived from the same map (label + color + count).
   - `lodSample.ts` — `uniformSampleIndices(total, cap≈500_000)` → stride =
     ceil(total/cap), returns Uint32Array of row indices (deterministic);
     `viewportIndices(positions, bounds, cap)` for zoomed-in region detail;
     both return the renderedToFull index mapping. Honest-label text builder.
   - `activitySizes.ts` — per-node size from real event data: subtle recency
     ramp on monthId (older→smaller, bounded range; uniform base).
   Focused vitest for each (stride math at 4,904,886 → ≤500k, determinism,
   mapping round-trip).
3. **`useActivityUniversePayload.ts`** — client hook: fetch `?meta=1` then the
   binary; decode via `lib/acc/columnarPayload`; expose {status, meta, columns,
   count, error}. Honest error on 404 (artifact absent) and decode failure.
4. **`ActivityUniverseShell.tsx`** — new client shell mounted by both routes:
   container div + `GraphCanvas2D` (frozen, no gpuSimulation, no ambient);
   on payload ready: build sampled subset (positions2, colors, sizes) →
   `setPointSet`; camera fit framing the sampled cloud; zoom-end listener flips
   to viewport detail set when the visible region ≤ cap, back to sample on
   zoom-out (LOD state machine kept tiny; labels update per state).
   Chrome: module legend, muted caption stack (LOD line, month floor line),
   `GraphLoadingSkeleton`-style loading state, honest error state. Zinc theme,
   reduced-motion static, no WebGL beyond the existing approved canvas.
   `activityTestBridge.ts`: behind `NEXT_PUBLIC_ACC_GRAPH_TEST=1` expose
   `window.__ACTIVITY_UNIVERSE_TEST__` = {isReady, residentCount, renderedCount,
   lodMode, stride} (Phase-41 re-baseline seam).
5. **Swap the mount**: `AccessAnalysisShellClient.tsx` renders
   `ActivityUniverseShell` (keep the `PersonGraph3D` opt-in flag branch —
   person-graph survives). Old `AccessAnalysisShell` stays on disk this plan
   (deleted in 39-03).
6. **Stop shipping instance bytes**: remove `prefetchAccessAnalysisRouteData`
   from `lib/server/acc-route-hydration.ts` (keep the /users prefetch fn);
   simplify `spatial-graph/page.tsx` + `users/access-analysis/page.tsx` — no
   graph queries left to prefetch → drop helpers/HydrationBoundary from these
   two pages only (do NOT touch the /users page seam; v2.4 PERF-04 trap).
