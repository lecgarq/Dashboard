# Plan 33-01 — PERF-05: shared hydration boundary fix

## Objective

Fix the app-wide SSR-hydration miss at the shared boundary: extract the
guarded `superjson.deserialize` fix (reference implementation
`spatial-graph/page.tsx:22-26`, commit 9fb54cb8) into one shared helper and
apply it at all three `<HydrationBoundary>` call sites, with a unit test.

## Context (@ paths)

- @.planning/phases/33-perf-closeout-verification/33-CONTEXT.md (PERF-05 boundary + defaults)
- @app/(dashboard)/users/spatial-graph/page.tsx (reference fix to extract)
- @app/(dashboard)/layout.tsx (raw call site 1 — helpers built inline, prefetches families/clash/sim/exam/kpi/trello)
- @app/(dashboard)/users/page.tsx (raw call site 2 — createAccRouteHelpers)
- @lib/server/acc-route-hydration.ts (ACC-only helper home — the new helper does NOT live here; layout.tsx prefetches non-ACC routers)

## Tasks

1. **Create `lib/server/hydrationState.ts`.**
   Export `deserializeHydrationState(state: unknown): DehydratedState` —
   if `(state as {json?: unknown}).json !== undefined`, return
   `superjson.deserialize(state as never) as DehydratedState`; else return
   `state as DehydratedState`. Plain module — no `import "server-only"`
   (pure data function; the unit test must import it under Vitest).
   Move the root-cause comment from `spatial-graph/page.tsx` here (the
   Pages-Router idiom explanation) so the "why" lives with the helper.
2. **Create `lib/server/hydrationState.test.ts`.**
   Two cases: (a) `superjson.serialize(<minimal DehydratedState>)` in →
   structurally-equal raw state out; (b) raw `DehydratedState` in → same
   reference out. Use a minimal real shape
   `{ mutations: [], queries: [{ queryKey: [...], queryHash: "...", state: {...} }] }`
   with a superjson-sensitive value (a `Date`) inside `state.data` so case (a)
   actually proves deserialization, not identity.
3. **Migrate `spatial-graph/page.tsx`** to
   `state={deserializeHydrationState(helpers.dehydrate())}`, deleting the
   inline guard block (comment moves to the helper).
4. **Fix `app/(dashboard)/layout.tsx:45`**: wrap `helpers.dehydrate()` in the
   helper. No other change to the layout.
5. **Fix `app/(dashboard)/users/page.tsx:13`**: same wrap.
