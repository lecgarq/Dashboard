## Decisions Made
- `summarizeFolderActivityByCompany` does NOT pin `UNKNOWN_COMPANY` the way `collapseCompanySlices` (companyCounts.ts) pins it for the existing donut — the plan's spec explicitly says "ranked like any other slice", so it can fall into "Other" like any real company. Losslessness is preserved because Other's aggregated count still includes it.
- Reused `buildRoleColorMap` (roleColors.ts) for company-bar coloring instead of writing a new company color-map function — it's a generic per-name palette cycler whose role-specific special-casing (`UNKNOWN_ROLE`/`MULTIPLE_ROLES`) simply never matches a company name, so it behaves as a plain stable-color assigner here. Kept the "Other" bar's distinct zinc `OTHER_COLOR`, matching `PermissionFootprintChart`'s convention.
