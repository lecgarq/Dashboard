<decisions>
## Implementation Decisions

*(All four areas below were presented interactively; Luis was AFK, so each records the
recommended default. Treat as decided-unless-overridden.)*

### Tab structure & storytelling
- **6 tabs, Overview-led:** Overview · Roles · Users · Companies · Projects · Compare.
  - Overview → Activity over time · Activity by module · Ingest freshness
  - Roles → Role distribution · Activity by role · Permission volume by level (PERM-01)
    · Activity recency by role (ENG-01)
  - Users → dormancy/recency detail and drill lists (the user-level cut of ENG-01)
  - Companies → Users by company · Activity by company · Folder activity by company (NEW)
  - Projects → Issue coverage donut · Model Coordination · (Ph21-22 issue charts land here)
  - Compare → folder permission terrain
- **Default tab: Overview.**
- **Filter scope: one global project picker + FilterBanner pinned above the tab strip;
  every tab (including Compare) reads the same selection.** This is the owner's explicit
  terrain ask ("cross-referenced with the main search bar"). Slice-level cross-filters
  remain shared across tabs (single sliceFilters bus, current behavior).

### ENG-01 pivot (activity recency by role)
- Replace the sign-in-recency panel: recency bands computed from each user's latest
  `AccActivityAccds` event, grouped by role.
- Reuse the locked band boundaries: <30d=[0,29], 30-90d=[30,90], 90-365d=[91,365],
  >365d=[366+], plus an explicit **"Never active"** bucket (lossless: band sums must
  equal row count — same invariant as 20-02).
- Coverage caption sourced live (accds covers 956/1,153 projects) — never hardcoded.
- The sign-in-recency chart is **removed**, not kept as a toggle (owner: "prefers
  activity recency instead of sign-in recency").

### PERM-01 reframe (permission volume by level)
- Horizontal stacked bars: one bar per role (top-N + "Other"), segments = permission
  level, valued by **count of folder permissions at that level** — directly answers
  "which role has the most admin permissions out of all".
- The bytes-sized footprint chart is **dropped**; `formatBytes` stays for any drill
  detail but bytes no longer size the headline chart.
- Permission-level vocabulary must map to the ACC-aligned `permissionMapping` levels
  (committed 8162f72) — VERIFY exact level names during research.
- Keep the existing per-role project drill map pattern from `PermissionFootprintChart`.

### Compare tab & terrain
- Terrain mounts inside the Compare tab; its own search bar/picker is **removed**;
  project selection comes from the global picker.
- Existing terrain view modes (including the Compare floating-planes mode) are
  preserved as-is — this phase relocates and rewires selection, it does not redesign
  the terrain itself.
- Empty state: Compare tab with no project selected shows the existing all-folders
  overview (`loadOverview`) rather than a blank pane.

### Folder activity by company (new graph)
- Top-10 companies by folder-scoped activity (`AccActivityAccds` rows with non-null
  `folderId`), each bar stacked by that company's top folders + "Other"; lives in the
  Companies tab.
- Users with no company mapping land in an explicit **"Unknown company"** bucket —
  labeled, never silently dropped.
- Click-to-drill lists folders/users per company, following the existing drill
  conventions.

### Claude's Discretion
- Role-click scroll-jump bug (UAT item 5): straight bug fix — diagnose and fix scroll
  behavior on slice-click; no product decision needed.
- Tab component implementation (existing Radix/shadcn tabs pattern vs URL-param-backed
  tabs), skeleton/loading behavior per tab, lazy vs eager data loading per tab, exact
  spacing/labels/empty-state wording.
- Whether `mainCharts.tsx`'s 11-entry `Promise.all` fan-out gets consolidated per-tab
  while wiring (STATE.md flags it for review once 3+ loaders share a domain).
- Chart shape fallbacks if research disproves a default (e.g., if company×folder
  stacking is too sparse, collapse to top-N companies with folder drill).

</decisions>
