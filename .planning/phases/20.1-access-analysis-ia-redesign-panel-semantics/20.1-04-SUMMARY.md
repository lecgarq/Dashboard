## Decisions Made
- Compute initial `mode`/`singleId`/`selected` via lazy `useState` initializers (evaluated once, at mount) rather than solely via a `useEffect`, so a component mounted with `externalSelectedIds` already present never issues a stray `loadTerrain` call against the old picker-default project on the first render before a correcting effect fires. A separate resync effect (guarded by a `didSyncExternalOnce` ref to skip its first run) then handles prop changes *after* mount.
- `deriveTerrainSelection`'s single/overview fallback branches populate `selected` with the best-known intersection/id list (not an empty array), so a later manual `ModeToggle` switch to compare mode keeps using externally-derived candidates, per the plan's explicit requirement.
