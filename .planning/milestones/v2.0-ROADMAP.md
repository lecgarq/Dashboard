# Milestone v2.0: Workshop-Grade UI/UX Overhaul

**Status:** ✅ SHIPPED 2026-06-19
**Phases:** 1–7
**Total Plans:** 30 (33 with gap-closure plans)

> **Version note:** This is the second shipped milestone of the LECG Dashboard. The prior milestone — **v1.0 — ACC Users Graph + Access Analysis Dashboard** (shipped 2026-05-08, tagged `v1.0`) — was archived before this project's fresh GSD re-initialization. This Workshop-Grade UI/UX Overhaul was internally numbered "v1.0" by the fresh project, but is tagged **v2.0** to avoid colliding with the existing `v1.0` tag and to reflect its standing as the next major version of the dashboard.

## Overview

A premium UI/UX overhaul of four existing pages (`/users`, `/access-analysis`, `/template-mty`, `/forma-proposal`) so the data looks, feels, and responds like a workshop showcase: fast, visually premium (2.5D depth — not flat), tactile, and explorable live. The stack was locked; this was presentation-layer surgery. The journey was foundation-first: ship the shared design language (depth/glow tokens, `PremiumSurface`, themed `EChart` wrapper, motion facade, slide-in `Sheet`) once so every page imports it. Then de-risk the largest structural liability — the 2,474-line `/users` monolith — by decomposing it behind a golden-path test before touching its visuals. Build the shared `DataTable` primitive once, then redesign the `/users` directory on it. With the foundation locked, the three per-page polish phases ran in parallel. A pre-workshop UAT on a projector was the only valid acceptance test.

## Milestone Summary

**Decimal Phases:** None — all integer phases (1–7).

**Key Decisions:**

- Premium 2.5D depth + *selective* 3D hero accents (CSS/ECharts depth on data pages; real R3F confined to `/users` header + `/forma-proposal` background) — honors "not flat" + "not overwhelming" + speed.
- Light + dark both first-class and equally refined.
- Mix treatment per page (`/users` full redesign on a new DataTable; others polish + depth + new views).
- New analytics bounded strictly to the existing Prisma DB; under-covered sources (e.g. `AccActivity` 428/1,152) labeled in the UI.
- Foundation-first build order: every per-page phase imports Phase 1 (tokens, PremiumSurface, EChart, motion facade, Sheet).
- "Raise the token, not the threshold" for WCAG AA: nudge chart label colors to meet contrast rather than loosening the 4.5:1 floor.
- Adopted the `scripts/repo-map` toolchain as the standing structural input for per-phase research + a regression ratchet (`repo-map:check`).
- Projector UAT (Phase 7) is the only valid acceptance test.

**Issues Resolved:**

- Decomposed the 2,474-line `/users` monolith → 314-line orchestrator shell + Zustand store + single data hook (zero user-visible change, guarded by a golden-path test).
- Eliminated the hydration-key cache-miss double-fetch (PERF-03 — each tRPC endpoint fetched once per load).
- WCAG AA chart-label contrast at projector brightness in both themes (THM-01), with an automated 15-assertion regression gate.
- Perpetual d3-force ticking on the role-similarity graph (settle-and-freeze).

**Issues Deferred (to v-next):**

- FRM-V2-01: Forma role-permission diff view (needs a new `template.getBaseline(roleId)` tRPC query).
- ACC-V2-01: Project-grouped persistent accordion in the `/access-analysis` project picker.
- NA-V2-01: Additional new analytics beyond the gated per-page set.
- `/users` data freshness/auto-refresh (pre-existing app-wide `refetchOnWindowFocus:false` + staleTime; confirmed not a Phase 2 regression).

**Technical Debt Incurred:**

- The reduced-motion (`prefers-reduced-motion`) runtime DevTools-emulation check is enforced at code level (15/15 unit tests) but the live browser media-query path remains a carried-forward manual verification item.
