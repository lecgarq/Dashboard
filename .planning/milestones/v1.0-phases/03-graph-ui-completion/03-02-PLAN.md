3. **Stability debounce effect (Canvas 2D path):**
   ```typescript
   useEffect(() => {
     if (!isReady || !hasReceivedTickRef.current) return;
     const STABLE_THRESHOLD = 0.0001;
     const STABLE_DURATION_MS = 500;
     const v = motionMetric.averageVelocity;

     if (v < STABLE_THRESHOLD) {
       if (stableStartedAtRef.current === null) {
         stableStartedAtRef.current = Date.now();
         // Schedule a re-check after the debounce window so we settle even if no further ticks arrive
         const handle = setTimeout(() => {
           if (stableStartedAtRef.current !== null && Date.now() - stableStartedAtRef.current >= STABLE_DURATION_MS) {
             setIsSimStable(true);
           }
         }, STABLE_DURATION_MS + 20);
         return () => clearTimeout(handle);
       } else if (Date.now() - stableStartedAtRef.current >= STABLE_DURATION_MS) {
         setIsSimStable(true);
       }
     } else {
       stableStartedAtRef.current = null;
       if (isSimStable) setIsSimStable(false);
     }
   }, [motionMetric.averageVelocity, isReady, isSimStable]);
   ```

4. **Cosmos alpha polling (Cosmos path):** When the active renderer is Cosmos (gate on existing `cosmosRendererRef.current` truthiness or whatever flag distinguishes the renderer), poll `getSimulationAlpha()` and `isSimulationRunning()` once per animation frame OR via a 100ms setInterval — whichever pattern matches the existing tick cadence in the file. Add a separate effect:
   ```typescript
   useEffect(() => {
     if (!isReady) return;
     const cosmos = cosmosRendererRef.current;
     if (!cosmos) return; // Canvas 2D path uses motionMetric effect above
     const id = window.setInterval(() => {
       const alpha = cosmos.getSimulationAlpha?.() ?? 1;
       const running = cosmos.isSimulationRunning?.() ?? true;
       const stableNow = alpha < 0.005 && !running;
       if (stableNow) {
         hasReceivedTickRef.current = true; // Cosmos path: alpha update counts as "tick"
         if (stableStartedAtRef.current === null) {
           stableStartedAtRef.current = Date.now();
         } else if (Date.now() - stableStartedAtRef.current >= 500) {
           setIsSimStable(true);
         }
       } else {
         stableStartedAtRef.current = null;
         if (isSimStable) setIsSimStable(false);
       }
     }, 100);
     return () => window.clearInterval(id);
   }, [isReady, isSimStable]);
   ```
   Adjust the API method names to match what `cosmosRendererRef.current` actually exposes — verify by reading CosmosGraphRenderer in graphRenderers.ts. Use optional-chaining + fallbacks if any method may be undefined.
