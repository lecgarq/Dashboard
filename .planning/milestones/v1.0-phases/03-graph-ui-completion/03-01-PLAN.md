<task type="auto">
  <name>Task 2: Add zoom-threshold label render pass to CanvasGraphRenderer.draw()</name>
  <files>app/(dashboard)/users/graphRenderers.ts</files>
  <action>
Add a label render pass to `CanvasGraphRenderer.draw()` that runs AFTER the existing node draw pass and BEFORE method return. Implement these behaviors exactly:

1. **Early-out:** If `frame.labelFadeStartScale == null || frame.labelFadeEndScale == null`, do nothing (back-compat).
2. **Compute opacity:** `opacity = clamp01((view.scale - fadeStart) / (fadeEnd - fadeStart))`. If `opacity <= 0` AND `labelOverrideIndices` is empty/undefined, skip the entire pass.
3. **Reset transform to screen space:** `ctx.resetTransform(); ctx.scale(dpr, dpr);` so labels are rendered at fixed pixel size regardless of world zoom.
4. **Font:** `ctx.font = "11px ui-sans-serif, system-ui, sans-serif"; ctx.textAlign = "center"; ctx.textBaseline = "alphabetic"; ctx.fillStyle = "#111827"; ctx.globalAlpha = opacity;`
5. **Build candidate list:** Iterate `frame.nodes`; skip nodes without `label`. For each candidate, compute screen position from `frame.positions[i*2]/[i*2+1]` using the same world→screen formula as the hit-test code in this file. Cull off-screen (with 50px margin).
6. **Priority sort:** Sort candidates by `degree` descending (undefined degree = 0). Nodes in `labelOverrideIndices` go FIRST (always drawn, always at top priority) and bypass the cap and collision check.
7. **Hard cap:** Stop drawing after 200 labels (override labels DO count toward the cap, but are guaranteed slots before normal labels are considered).
8. **Collision resolution:** Maintain a list of drawn AABBs `[x, y, w, h]` in screen pixels. For each non-override candidate, compute `textWidth = ctx.measureText(label).width + 4` and AABB `[sx - textWidth/2, sy - 18, textWidth, 14]` (label sits above the node). If overlaps any drawn AABB, skip it. Override labels are drawn unconditionally, but their AABBs are added to the drawn set so subsequent normal labels respect them.
9. **Draw:** `ctx.fillText(label, sx, sy - 8)` (8px above node center in screen pixels — labels appear above the node dot).
10. **Reset:** `ctx.globalAlpha = 1;` at end.

Do NOT add label code to `CosmosGraphRenderer.draw()` (Pitfall 4 in RESEARCH.md). Do NOT use rbush or any external collision library — O(n²) AABB at n≤200 is <1ms (RESEARCH.md "Don't Hand-Roll").

Use the existing `dpr` (device pixel ratio) the renderer already tracks for the canvas. If unavailable as a class field, read from `window.devicePixelRatio || 1` at draw time (cheap).

Watch out for: the existing draw method may already call `ctx.resetTransform()` at start and apply world-to-screen transforms — confirm by reading the file before editing. Place the label pass at the END so it runs in screen space without disrupting the node draw pass.
