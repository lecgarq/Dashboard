  <name>Task 2: Add auto-collapse-on-detail-open at narrow viewports</name>
  <files>app/(dashboard)/users/AccUsersGraph.tsx</files>
  <action>
Add a useEffect that auto-collapses the filter panel when the detail panel opens AND the viewport is ≤1280px wide. This preserves the ≥720px graph canvas constraint.

```typescript
useEffect(() => {
  if (!selectedNode) return;
  // Only auto-collapse on narrow viewports where both panels can't fit alongside graph
  if (typeof window === "undefined") return;
  const isNarrow = window.matchMedia("(max-width: 1280px)").matches;
  if (isNarrow && !isFilterCollapsed) {
    setIsFilterCollapsed(true);
  }
}, [selectedNode, isFilterCollapsed]);
```

Constraints:
- Trigger ONLY on `selectedNode` becoming truthy at ≤1280px. Do NOT auto-expand when detail closes — user-initiated state should not be overridden.
- If the user manually expands the filter while detail is open at 1280px (and accepts the squeezed canvas), respect their choice — do NOT re-collapse on next render. The effect's dependency on `isFilterCollapsed` ensures we only auto-collapse once per `selectedNode` transition.
- Use `matchMedia` (not `window.innerWidth`) to handle DPR/zoom edge cases consistently.
- SSR guard: `typeof window === "undefined"` — Next.js client component but defensive anyway.
- Do NOT listen for matchMedia changes (resize) — that would fight user resize behavior. Auto-collapse triggers only on selection events.

Note: At >1280px viewports, both panels fit alongside a >720px graph (per RESEARCH.md width math), so no auto-collapse needed.
