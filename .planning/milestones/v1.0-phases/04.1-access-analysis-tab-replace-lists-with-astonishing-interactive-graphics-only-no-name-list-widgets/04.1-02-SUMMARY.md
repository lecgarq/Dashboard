## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] d3-hierarchy generic type signature**
- **Found during:** Task 1 typecheck
- **Issue:** Plan implied a `{ children: Leaf[] }` root passed straight into `hierarchy()`, but d3-hierarchy's `hierarchy<T>(root, children)` requires the children accessor to return `Iterable<T> | null | undefined` of the SAME `T` — a `Leaf[]` return shape doesn't satisfy that and the cast `as unknown as Leaf` on `node.data` triggered TS2352 ("neither type sufficiently overlaps").
- **Fix:** Introduced `PackNode = { _value?: number; children?: PackNode[] } & Partial<Leaf>` so the root and leaves share one type; `pack<PackNode>()` works, and `node.data as unknown as Leaf` becomes legal at the leaf boundary because `PackNode` carries `Partial<Leaf>`.
- **Files modified:** `app/(dashboard)/users/dashboard/widgets/RecommendationsWidget.tsx`
- **Commit:** e1a693a
