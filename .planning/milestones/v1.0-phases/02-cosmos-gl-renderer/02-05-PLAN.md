<objective>
Swap the d3-force CPU worker for Cosmos's native GPU force-directed physics on the GPU rendering path, so the graph remains interactive at 25,000+ nodes.

Purpose: Closes TD-005 (logged in 02-03 SUMMARY). User testing of 02-03 surfaced that the production ACC hub has 25,602 nodes — 50× the plan's stated 500-node target. d3-force runs on the CPU and produces a 287ms physics tick at that scale, making sliders/picker/filter feel frozen. Cosmos.gl was specifically built to run force-directed layout on the GPU and is benchmarked for 100k+ nodes, so the fix is to stop bypassing the engine that's already loaded.

Output: A renderer that uses Cosmos's built-in `simulationRepulsion`, `simulationLinkSpring`, `simulationLinkDistance`, `simulationCluster` (etc.) for live physics, with the existing d3-force worker retained ONLY as the Canvas2D fallback.

Reference:
- Cosmos config (simulation* fields): https://cosmos.gl/api/
- Cosmos clusters story (target slider feel): https://cosmos.gl/?path=/story/examples-clusters--with-labels
</objective>

```typescript
interface GraphConfigInterface {
  enableSimulation: boolean;          // INIT-ONLY — must be true to use GPU physics
  simulationRepulsion: number;        // ~0.1 weak .. ~2.0 strong
  simulationLinkSpring: number;       // 0..2 (link rigidity)
  simulationLinkDistance: number;     // target link length in sim space
  simulationCluster: number;          // 0..1 cluster pull
  simulationGravity: number;          // 0..1 pull toward center
  simulationFriction: number;         // 0..1 (default ~0.85)
  simulationDecay: number;            // alpha decay coefficient
  simulationCenter: number;           // centering force coeff
  onSimulationStart?: () => void;
  onSimulationTick?: (alpha: number, hovered, ...) => void;
  onSimulationEnd?: () => void;
}

class Graph {
  setConfig(partial: Partial<GraphConfigInterface>): void;
  setPointClusters(clusters: (number | undefined)[]): void;
  setClusterPositions(positions: (number | undefined)[]): void;
  setPointClusterStrength(strengths: Float32Array): void;
  start(alpha?: number): void;
  pause(): void;
  unpause(): void;
  get isSimulationRunning(): boolean;
  get progress(): number;          // simulation alpha
}
```
