CameraTween reads selected node position via the position-mirror (cheaper than per-frame readbacks).

createPositionMirror({ renderer, physics, hz = 2 }) returns:
```ts
interface PositionMirror {
  /** Latest mirrored positions, Float32Array of length 4*textureWidth^2 (RGBA, xyz=pos). */
  buffer: Float32Array;
  /** Monotonic counter incremented each refresh — consumers gate work on this. */
  version: number;
  /** Call inside useFrame; internally throttles to `hz` Hz. */
  tick(now: number): void;
  dispose(): void;
}
```
