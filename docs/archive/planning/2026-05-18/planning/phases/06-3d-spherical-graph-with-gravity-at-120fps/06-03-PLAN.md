  <action>
Create `topologyAdapter.ts`:
- Export `ACC_MAX_EDGES_PER_NODE = 16` (tunable; covers most clusters at production scale).
- Export `buildEdgeBuffers(nodes: AccGraphInstanceNode[]): { edgeIndexTexData: Float32Array; edgeLookupTexData: Float32Array; edgeIndexWidth: number; edgeLookupWidth: number; totalEdgeSlots: number }`.

Implementation:
1. Call `buildAccTopologyGraph(nodes)` (import from `../accGraphOrganicLayout`).
2. Group links by source-node index. For each node, sort its outgoing links by `weight` descending, keep top `ACC_MAX_EDGES_PER_NODE`.
3. Pack each node's kept-edges contiguously into `edgeIndexTexData` (a Float32Array of `[targetIdx, weight, 0, 0]` per slot — 4 floats per texel for RGBA float texture).
4. Build `edgeLookupTexData`: 1 texel per node, RGBA = `[startSlot, count, 0, 0]`.
5. Choose square texture widths: `edgeLookupWidth = ceil(sqrt(nodeCount))`, `edgeIndexWidth = ceil(sqrt(totalEdgeSlots))`. Pad to width*width texels with zeros.
6. Symmetrize: when packing node A → B, also add B → A's slot list (graph is undirected). If symmetrization would exceed ACC_MAX_EDGES_PER_NODE, drop the weakest existing edge for that side.

Test `topologyAdapter.test.ts`:
- 4-node line graph (A-B-C-D) → each interior node has degree 2, ends have degree 1, all symmetric.
- A 20-node graph where one hub has 30 neighbors → output caps that node at 16, keeps top-16 by weight.
- Texture dims: `edgeLookupWidth * edgeLookupWidth >= nodeCount`, `edgeIndexWidth * edgeIndexWidth >= totalEdgeSlots`.
- Perf smoke: build buffers for 25,000 synthetic nodes + 100k random links in under 500ms (use `performance.now()` boundary).
