GPU pick canonical pattern from RESEARCH Code Example #4 — re-read; do not deviate.

PickApi contract (the wiring channel between PickPoints and the host consumer + replay harness):
```ts
export interface PickApi {
  /** Pick by CSS pixel coords (relative to canvas). Returns node index or -1 (background). */
  pickAt(cssX: number, cssY: number): number;
  /** Dispose internal 1x1 render target. */
  dispose(): void;
}
```
PickPoints accepts `onReady: (api: PickApi) => void` — parallel to PhysicsCompute's onReady(PhysicsApi) pattern.

BOTH the host (Sphere3DGraph in 06-09) AND the replay-mode `window.__sphere3dPickAt` debug hook use this SAME channel: PickPoints calls onReady once with a stable api, host stores it, and under `?replay=1` PickPoints also assigns `window.__sphere3dPickAt = api.pickAt` so Playwright can deterministically pick from the test runner.
