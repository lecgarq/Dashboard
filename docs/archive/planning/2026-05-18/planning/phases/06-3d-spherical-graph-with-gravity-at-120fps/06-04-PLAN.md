  <action>
Each file exports a `default` string of GLSL3 fragment shader source consumed by GPUComputationRenderer (TS exports keep the bundler happy without raw-string imports).

positionStep.frag (texturePosition):
- `uniform float uDelta;` (replay-mode override happens in JS by setting uDelta = REPLAY_FIXED_DELTA)
- Reads current pos from `texturePosition`, vel from `textureVelocity`, integrates pos += vel * uDelta, writes RGBA(pos.xyz, _).
- Damping: `vel *= 0.96` is in velocity shader, not here.

velocityStep.frag (textureVelocity):
- Uniforms: `uDelta`, `uClusterCenters[MAX_CLUSTERS]` (vec3 array, MAX_CLUSTERS=64), `uClusterGravity` (0.6), `uRepulsion` (0.2), `uEdgeSpring` (0.4), `uDamping` (0.96), `uHiddenOutwardForce` (1.2), `sampler2D uEdgeIndexTex`, `sampler2D uEdgeLookupTex`, `sampler2D uParamsTex`, `float uEdgeIndexWidth`, `float uEdgeLookupWidth`, `float uTextureWidth`.
- Per-node attribute via texelFetch on `uParamsTex` (RGBA float): R=`aClusterId` (negative = ghost), G=`aVisible` (0..1; 1 = visible, 0 = filtered-out).
- Early-return if `aClusterId < 0` (ghost texel — Pitfall 5).
- Force accumulation:
  1. Cluster gravity: `force += (uClusterCenters[clusterId] - pos) * uClusterGravity * aVisible` — visible nodes are pulled inward; hidden nodes lose their inward pull.
  2. **Outward drift for hidden nodes (CONTEXT-locked behavior):** `vec3 outward = normalize(pos - uClusterCenters[clusterId]); force += outward * uHiddenOutwardForce * (1.0 - aVisible);` — when aVisible→0, node gets a steady radial push away from its cluster center, drifting it outward through (and past) the ball envelope. Combined with the nodeRender alpha fade in 06-05, this produces the "fade AND drift outward" CONTEXT-locked motion.
  3. Edge spring: read lookup texel `(startSlot, count)` → loop up to ACC_MAX_EDGES_PER_NODE (constant, defined via `#define`); for each, sample edge index tex → `(targetIdx, weight)` → read target pos from texturePosition by index → spring force scaled by `aVisible` (hidden nodes don't tug visible neighbors).
  4. Soft repulsion: sample 6 jittered neighbors in cluster-space (or skip — clusters auto-separate). Keep cheap. Gate by aVisible so hidden nodes don't repel visible ones.
- Damp: `vel = (vel + force * uDelta) * uDamping`.
- Write to gl_FragColor.

Hard rule: NO `Math.random()` equivalent (no fract(sin) jitter that varies per frame); any pseudo-randomness uses gl_FragCoord-based deterministic hashing.

Create `PhysicsCompute.tsx` ("use client"):
- Props: `{ nodes: AccGraphInstanceNode[]; onReady?: (api: PhysicsApi) => void }`.
- Export `interface PhysicsApi { getPositionTexture(): THREE.Texture; getParamsTexture(): THREE.DataTexture; getNodeCount(): number; getTextureWidth(): number; reseed(): void; setVisibility(visibility: Uint8Array | Float32Array): void; }`.
- `setVisibility(v)` writes per-node aVisible (0..1) into the G channel of the params DataTexture and flips `params.needsUpdate = true`. This is the channel 06-05's filter pipeline uses so the velocity shader can read aVisible and apply the outward-drift force (CONTEXT-locked "drift outward" behavior).
- On mount (in a `useEffect` keyed on `nodes.length` for identity stability):
  1. `useThree()` to grab `gl` (THREE.WebGLRenderer).
  2. Assert `gl.capabilities.isWebGL2` AND `gl.getContext().getExtension('EXT_color_buffer_float')`. On failure, call `onReady(null)` or surface an error (Sphere3DGraph will render an empty-state in Wave 5).
  3. Compute `WIDTH = Math.ceil(Math.sqrt(nodes.length))`.
  4. Run `assignClusterIds(nodes)` + `buildClusterCentroids(clusterCount)` + `buildEdgeBuffers(nodes)`.
  5. For each node, compute initial position: pick cluster centroid, displace by `radialDistance(node) * jitterUnitVector` where jitter is seedrandom-driven (createSeededRng) so replay mode is deterministic.
  6. Fill position texture (Float32Array of WIDTH*WIDTH*4) and create a separate **params DataTexture** (RGBA float, WIDTH×WIDTH): R=aClusterId (set to -1 for ghost texels at index ≥ nodes.length, otherwise the assigned cluster id), G=aVisible (default 1.0 for visible-on-init), B/A reserved. The velocity shader samples this texture; `setVisibility()` mutates the G channel and 06-05 calls this on filter change.
  7. Fill velocity texture with zeros.
  8. `new GPUComputationRenderer(WIDTH, WIDTH, gl)` from `three/examples/jsm/misc/GPUComputationRenderer.js`.
  9. Wire variables per RESEARCH Code Example #2 (positionVariable, velocityVariable, dependencies set both ways).
  10. Set uniforms: cluster centers (Float32Array → THREE.DataTexture or uniform array — note GLSL3 doesn't allow runtime-sized arrays; use #define MAX_CLUSTERS and pad), edge textures (THREE.DataTexture, `THREE.RGBAFormat`, `THREE.FloatType`), uTextureWidth.
  11. Call `gpuCompute.init()`. If error, throw with the message (will crash the dev build loudly — Wave 5 adds graceful empty-state).
- `useFrame((_, delta) => { uVel.uniforms.uDelta.value = isReplayMode() ? REPLAY_FIXED_DELTA : Math.min(delta, 1/30); gpuCompute.compute(); })`.
- Cleanup on unmount: dispose textures + renderTargets.
- Memoize via ref so `onReady` is called exactly once with the stable API object.
