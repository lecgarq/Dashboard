   ```typescript
   }
   ```

3. `export async function fetchHubRoles(accountId: string, accessToken: string): Promise<HubRole[]>`:
   - URL: `${HQ_V2_BASE}/accounts/${accountId}/industry_roles`
   - Call `fetchHqUsers(url, accessToken)`.
   - Map raw items: `{ id: String(raw.id), name: String(raw.name), memberCount: typeof raw.member_count === "number" ? raw.member_count : 0 }`.
   - Filter out entries missing `id` or `name` (defensive).

4. `export async function extractAndPersistHubRoles(prisma: PrismaClient, accountId: string, accessToken: string): Promise<HubRole[]>`:
   - Fetch via `fetchHubRoles`.
   - For each role: `prisma.accRole.upsert({ where: { id: role.id }, create: { id, accountId, name, memberCount, syncedAt: new Date() }, update: { accountId, name, memberCount, syncedAt: new Date() } })`.
   - Log: `[quick-sync] hub roles: {count} upserted`.
   - Return the role array (plan 02-03 needs it for fallback name→ID resolution).

5. NO soft-delete in this phase — APS doesn't return a stable "all known roles" view that's safe to diff against. Defer cleanup to v2.x CLN bucket.
