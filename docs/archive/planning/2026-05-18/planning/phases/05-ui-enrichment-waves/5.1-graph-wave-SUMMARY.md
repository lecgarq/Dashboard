## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] isAccountAdmin not on AccProjectMember**
- **Found during:** Task 1
- **Issue:** Plan interface block stated `isAccountAdmin Boolean` is on `AccProjectMember` (verified from schema). Actual schema has NO `isAccountAdmin` on `AccProjectMember` — it's on `AccMemberCache`/`BulkAccUser` (from HQ v1 sync in Phase 2).
- **Fix:** `enrichedUsers` omits `isAccountAdmin` (it's already non-optional on `BulkAccUser` from Phase 2 Plan 04). `adminTierFor()` reads from `BulkAccUser.isAccountAdmin` directly during node-build in `AccUsersGraph`.
- **Files modified:** `server/routers/acc-members.ts`, `app/(dashboard)/users/AccUsersGraph.tsx`

**2. [Rule 1 - Bug] permissionTierEdgeColor: Full Controller and View+Download+Upload+Edit resolved to same RGBA**
- **Found during:** Task 1 test run
- **Issue:** Logic `canDelete || (canEdit && canDownload && canUpload && canView)` caused "edit+view+download+upload" (no delete) to be bucketed as Full Controller.
- **Fix:** Split condition — `canDelete` alone is Full Controller; `canEdit && canDownload && canUpload && canView` (without delete) is the Edit tier. 2 failing tests → all 10 pass.
- **Files modified:** `app/(dashboard)/users/folderCluster.ts`

**3. [Rule 2 - Missing] hoverEmail sync effect added**
- **Found during:** Task 2 implementation
- **Issue:** Plan specified lazy file-activity query in tooltip but didn't provide a mechanism to sync `hoverEmail` across all hover call sites (3D renderer, Cosmos renderer, Canvas 2D renderer all update `hoveredNode` independently).
- **Fix:** Single `useEffect(() => { setHoverEmail(hoveredNode?.email ?? null); }, [hoveredNode])` avoids modifying all 4 hover call sites.
- **Files modified:** `app/(dashboard)/users/AccUsersGraph.tsx`

## FPS Performance

Admin tier overlay uses `setPointShapes()` + `setPointSizes()` on a `useEffect` trigger (not per-frame). Buffer rebuild is O(N) one-time cost on toggle — no per-frame overhead. Baseline size is 7px (same as cosmos default). Hub admin nodes are 10.5px (1.5×). No measurable FPS regression expected for typical hub sizes (<5,000 nodes). Profiling deferred to UAT Step 5.
