    4. **How to install the scheduled task** (copy-pastable PowerShell — Luis is non-technical):
       ```powershell
       # Run from elevated PowerShell prompt (Right-click PowerShell -> Run as Administrator)
       $action = New-ScheduledTaskAction -Execute 'pwsh.exe' -Argument '-File "C:\LECG\Dashboard\scripts\dc-daily-cron.ps1"'
       $trigger = New-ScheduledTaskTrigger -Daily -At '3:00am'
       $settings = New-ScheduledTaskSettingsSet -StartWhenAvailable -DontStopIfGoingOnBatteries -AllowStartIfOnBatteries
       Register-ScheduledTask -TaskName 'LECG-DC-Daily-Ingest' -Action $action -Trigger $trigger -Settings $settings -RunLevel Highest -Description 'Phase 8 daily APS Data Connector ingest'
       ```

       Trigger a manual test run with: `Start-ScheduledTask -TaskName 'LECG-DC-Daily-Ingest'`
    5. **How to pause / resume**:
       - **Quick pause (one-time skip next run):** create `.dc-ingest.disabled` at `C:\LECG\Dashboard\.dc-ingest.disabled`. Delete to resume.
       - **Long pause:** `Disable-ScheduledTask -TaskName 'LECG-DC-Daily-Ingest'`. Re-enable with `Enable-ScheduledTask`.
    6. **How to re-authenticate Autodesk**:
       - Open the dashboard.
       - When the SyncFreshnessPill is RED, click it.
       - Browser redirects to Autodesk OAuth; sign in.
       - Next scheduled run picks up the refreshed token automatically.
    7. **Log locations**:
       - `C:\LECG\Dashboard\logs\dc-ingest-YYYY-MM-DD.log` (PowerShell harness)
       - Console output of `node scripts/dc-daily-ingest.cjs` (for manual debug runs)
       - DB table `AccDcIngestRun` — `SELECT * FROM "AccDcIngestRun" ORDER BY started_at DESC LIMIT 5;`
    8. **Common errors and fixes**:
       - **HTTP 429** (quota exhausted): pill goes amber; resume tomorrow automatic.
       - **HTTP 401 / token expired**: pill goes red; click pill to re-auth.
       - **HTTP 504 on submit**: backoff retry built in; if persists 4+ times, APS DC is down — pause overnight.
       - **Anomaly quarantine**: pill amber + AccDcIngestRun.status='quarantined' + errorMessage describes which threshold tripped. Inspect; if false positive, raise the threshold in `lib/acc/dcAnomalyChecks.ts` DEFAULT_THRESHOLDS.
       - **Stale lock**: another run is in-flight (or crashed). 60min old runs are reclaimed automatically. To force-reclaim earlier, manually update the row: `UPDATE "AccDcIngestRun" SET status='failed', ended_at=NOW() WHERE status='running';`
       - **Unknown module detected**: Autodesk added a 10th module. Open `lib/acc/dcActivityCsvIngest.ts`, add the module name to `KNOWN_MODULES`, add a color to `MODULE_BADGE_COLORS` in `UsersDirectoryClient.tsx`, redeploy.
    9. **How to manually trigger one ingest right now** (debug):
       ```cmd

       ```
    10. **Health check**: open dashboard, hover the SyncFreshnessPill. If it shows green + "last success <24h" + nonzero "Backfill" + nonzero quota -> healthy.
