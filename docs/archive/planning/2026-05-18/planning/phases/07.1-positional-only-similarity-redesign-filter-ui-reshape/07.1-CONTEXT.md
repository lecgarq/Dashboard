# Phase 07.1: Positional-only similarity redesign + filter UI reshape - Context

**Gathered:** 2026-05-12
**Status:** Ready for planning

<domain>
## Phase Boundary

Convert the 5 user↔user similarity dimensions (folder-access, roles, projects, company, admin-tier) and the 4 permission tiers (view / upload / edit / control) from **visible parallel edges/ribbons** (shipped in Phase 7) into **positional clustering forces** (similarity) and **node-level visuals** (tiers via pie-glyphs). Reshape the filter UI so its controls match the new mental model — sliders that affect node *position*, not toggles that show/hide edges.

In scope:
- 2D `AccUsersGraph` (cosmos.gl) — full redesign
- Filter UI shape changes on the 2D surface
- Data path refactor of `computeSimilarityEdges` consumption (force-only, not render)
- Pie-glyph node rendering for permission tiers (2D)
- URL param continuity (existing keys kept, one new key `simStr` added)
- Done gate: flip the `false until positional-only lands` flag at `app/(dashboard)/users/AccUsersGraph.tsx:69` to true + visual UAT on prod data

Out of scope (follow-up phases):
- 3D `Sphere3DGraph` parity (pie-glyphs + full filter UI reshape)
- New view modes beyond user-only
- Any expansion of the similarity/tier model (new dims, new tiers)

</domain>

<decisions>
## Implementation Decisions

### Similarity → layout mechanism
- **Invisible link force per dimension.** Reuse `computeSimilarityEdges`; split its output into "render links" (empty after this phase) and "force links" (fed to the layout engine).
- **Per-dim strength sliders, one per dimension (5 sliders), domain 0–1.**
- **Default strength = 1.0 per dim**; user tunes from there. Neutral starting point, no opinionated weighting.
- **`simMin` (minimum shared attributes) survives** as a *layout-only cutoff* — pairs below threshold contribute zero attraction. Same slider, repurposed.
- **Dim toggle OFF → strength → 0 with live reflow** (smooth perturbation, not full restart).
- **Top-K neighbor cap** per user to bound force count at hub scale (~1000+ users). Specific K picked during planning.
- **2D and 3D share one 0–1 slider domain**, normalized per engine (cosmos.gl vs r3f physics units).

### Filter UI reshape
- Rename the "Topology" section to **"Clustering"**.
- Each dim row = **checkbox + strength slider 0–1**.
- `simMin` lives at the bottom of the Clustering section as **"Minimum similarity"**.
- **"User-only view" toggle is promoted to a top-level toggle** above all sections (it's a view-mode switch, not a clustering knob).
- Tier swatches in the filter panel double as the on-screen legend (no separate legend chrome).

### Permission tiers — visual representation
- **User nodes show pie-glyph segments** for their tier portfolio (revives the earlier-phase pie-glyph pattern referenced in `[[feedback_similarity_positional_only]]`).
- **Pie-glyph size scales with zoom, clamped [6px, 14px]** (mirrors the existing label polish curve from `[[project_label_polish_curve]]`).
- Users with **no permissions** render as a solid neutral node, no pie.
- Hovering a user node surfaces a **full tier breakdown + sample folders** tooltip card (like the existing folder-count tooltips in `AccUsersGraph`).
- **`role↔folder` edges keep tier-color** (colored by highest tier on the edge) — these are real ACL relationships, so tier-color here is honest signal, not the Phase 7 mistake (which colored *fake* tier-only ribbons with no real edge underneath).
- **Tier filter OFF → hide users whose max tier matches the unchecked tier.** Pure node-level filter; no edges to think about.

### Surviving visible-edge inventory (after 07.1)
- `role↔folder` — visible, colored by highest tier
- `folder↔project` — visible, neutral color
- **All similarity edges:** not drawn (force-only)
- **All other tier-only ribbons:** removed

### Rollout
- **2D-first.** Ship the complete redesign to `AccUsersGraph` (cosmos.gl) in 07.1.
- **3D follow-up phase** handles `Sphere3DGraph` parity (pie-glyphs, full filter UI reshape). 3D in 07.1 may receive only the layout-force conversion + section rename if it falls out cheaply; full glyph + filter parity is explicitly deferred.

### URL persistence
- **Reuse existing keys:** `ptiers`, `simDims`, `simMin`, `view`, `folders` — semantics unchanged from Phase 7.
- **Add `simStr`** — per-dim strength array (default 1.0 each). Existing URLs from Phase 7 keep working; new key opt-in.

### Done gate
- Flip `app/(dashboard)/users/AccUsersGraph.tsx:69` flag from `false` to `true` (Phase 7 left it gated for this redesign).
- **Visual UAT on prod data at hub scale**, confirming: no similarity edges drawn, pie-glyphs render, Clustering filter section works, user-only view toggle promoted, role↔folder still tier-colored.

### Claude's Discretion
- Exact top-K neighbor cap value (likely K=15–30; pick based on perf measurement during planning).
- Pie-glyph shader implementation details (cosmos.gl custom node shader path vs SDF approach).
- Slider visual styling, debounce timing on strength changes.
- Tooltip card layout details for the "full tier breakdown + sample folders" content.
- Whether to deprecate or just hide the old "Topology" section heading (planner picks the cleanup approach).
- Whether 3D receives the cheap subset (force conversion + section rename) in 07.1 or all 3D work is deferred.

</decisions>

<specifics>
## Specific Ideas

- Mental model anchor: similarity = *where nodes sit*, tiers = *what each node carries*. Neither = *what edges to draw*.
- Pie-glyph precedent: earlier phases in `/users` already had pie-chart node glyphs; this phase brings them back rather than inventing a new visual.
- Edge honesty rule: tier-color is allowed only on edges that exist for real ACL reasons (i.e. `role↔folder`). It's never allowed to spawn edges.
- Reuse over rewrite: `computeSimilarityEdges` stays, the renderer-feeding code path is what changes.

</specifics>

<deferred>
## Deferred Ideas

- 3D `Sphere3DGraph` full parity (pie-glyphs, full Clustering filter section) — its own follow-up phase.
- "Suggest collaborators" UX built on similarity — future phase, not 07.1.
- New view modes beyond user-only (project-only, role-only) — extensibility hook only, not built here.
- Per-dim threshold (separate `simMin` per dimension) — single global `simMin` for now.
- Domain-tuned default strengths (e.g. shared-projects weighted higher than admin-tier) — defaults stay equal at 1.0; user tunes.
- Empty-ring outline for no-permission users as a "spot orphans" visual — solid neutral node for now.

</deferred>
