    1) `"use client"`. Import `ReactECharts` from `echarts-for-react`.
    2) Props: `{ users: BulkAccUser[] }`.
    3) `useMemo` aggregation:
       - Iterate `users[].projects[].roles + .modules` → build distinct sorted `roles` and `modules` arrays.
       - Build `counts: Map<roleKey|moduleKey, number>` of distinct member counts (NOT raw assignments — count distinct user emails per role-module cell, since one user can have a role+module via many projects but they should count once).
       - Build `matrix: [moduleIdx, roleIdx, count][]`.
    4) ECharts option:
       - `tooltip: { position: "top", formatter: (p) => `${roles[p.value[1]]} × ${modules[p.value[0]]}: ${p.value[2]} members` }`.
       - `grid: { left: 140, right: 30, top: 30, bottom: 80 }`.
       - `xAxis: { type: "category", data: modules, axisLabel: { rotate: 45 } }`.
       - `yAxis: { type: "category", data: roles }`.
       - `visualMap: { min: 0, max: <max count>, calculable: true, orient: "horizontal", left: "center", bottom: 10 }`.
       - `dataZoom: [{ type: "inside" }]`.
       - `series: [{ type: "heatmap", data: matrix, label: { show: false }, emphasis: { itemStyle: { borderColor: "#000", borderWidth: 1 } } }]`.
    5) Container `<div style={{ height: 500 }}>` and `notMerge lazyUpdate` props on `<ReactECharts>` (Pitfall 2 + perf).
    6) Download CSV button: rows are `roles.flatMap(r => modules.map(m => ({ Role: r, Module: m, Members: counts.get(`${r}|${m}`) ?? 0 })))`.
    7) Empty users → render "No data — sync ACC first" inline message instead of an empty heatmap.

    Avoid: storing ECharts option inline at module scope (each render produces a new option object — but ECharts dedupes by deep-equal; `lazyUpdate` is the correct optimization); using the count of role-module ASSIGNMENTS (must be distinct member count or the heatmap inflates).
