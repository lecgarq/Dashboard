# Phase 02.5 Plan 03: Renderer + Side-Panel Display Summary

**Cosmos.gl zero-size hide via setVisibleIndices, Canvas2D edge-skip for filtered endpoints, 150ms CSS fade on filter change, and Company Role row in AccUserSidePanel.**

## Accomplishments

- `CosmosGraphRenderer.setVisibleIndices(visibleSet)` zeroes point sizes for excluded indices via `setPointSizes`, identity-cached to avoid GPU upload churn on steady-state redraws
- `CanvasGraphRenderer.draw()` edge loop now skips links where either endpoint index is absent from `frame.userIndices` (the visible filtered set); node rendering already correctly iterated only `userIndices`
- `isFilterTransitioning` state in `AccUsersGraph.tsx` triggers a 150ms CSS opacity dip on a new wrapper div around the canvas and Cosmos container; pure CSS, zero WebGL/GPU cost
- `AccUserSidePanel.tsx` renders a "Company Role" row between the stats grid and candidate analysis section; shows `user.companyRole ?? "Unspecified"`
- `BulkAccUser` extended with optional `companyRole?: string | null` field (backward compatible, no API migration required)

## Output Notes (per plan spec)

**Canvas2D edge loop status:** The Canvas2D node loop already iterated only `frame.userIndices` (excluded nodes were already skipped). The edge draw loop, however, drew ALL edges unconditionally. A new gate was added: build a `Set<number>` from `frame.userIndices` and `continue` if either edge endpoint is absent. This adds one Set construction per draw call — acceptable overhead since the canvas path is only active in the Canvas2D fallback backend.

**`setVisibleIndices` hook point:** Called from the filter effect in `AccUsersGraph.tsx`, immediately after `rebuildVisibleIndices()` updates `visibleIndexSetRef.current`. This ensures the Cosmos renderer's point size buffer is updated atomically with the React-side visible set.

**Cosmos v3 `setPointSizes` behavior:** No new API traps encountered. `setPointSizes` accepts a `Float32Array` of per-node sizes, consistent with the existing `buildNodeSizeBuffer` usage in `draw()`. The `typeof this.graph.setPointSizes === "function"` guard was already in place for the node-count change path — the same guard is applied in `setVisibleIndices`.

**Side-panel Row placement:** Between the stats grid (Projects/Active/Admin on) and the candidate analysis section (Junk Roles/Module Discrepancies). Uses the same inline flex label/value style as the rest of the panel body — no badge, no chip, plain text with truncation.
